# 05-M 식물성 섬유: 채집에서 직조까지

작성: 2026-10-27. 신규 콘텐츠 05-M 섬유 기초 확장. **수량·재생·시간은 임시 밸런스**, 인벤토리 음식/신앙/경제 시스템에는 영향 없음.

| 원천 | 실제 획득 지역 | 원천 아이템 | 가공 산물 |
|---|---|---|---|
| 갈대 | 습지 | item05a:reed | 갈대 섬유 |
| 아마 | 초원·농경지 | item05a:flax | 아마 섬유 |
| 쐐기풀 | 숲 | item05a:nettle | 쐐기풀 섬유 |

### 실행 가능한 제작 사슬
1. 각 식물 줄기 ×2 → 해당 식물 섬유 ×2 (300초).
2. 방적 가능한 식물 섬유(갈대/아마/쐐기풀, 혼합 가능) ×2 → 식물성 실 ×2 (300초).
3. 식물성 실 ×3 → 식물성 천 ×1 (600초).
4. 갈대 섬유 ×3 + 식물성 실 ×1 → 갈대 돗자리 ×1 (600초).

### 구현 계약
- 신규 가공품 총 6종과 제작법 6개를 기존 작업대 및 `mineral.refine` 제작 처리기에 등록.
- 아이템 카탈로그에 이미 있던 갈대(`item05a:reed`) ID를 재사용하고, 신규 아마·쐐기풀 아이템은 기존 05-A 네임스페이스로 등록.
- 05-A 기본 채집은 해당 지역·발견·고갈·재생 조건을 따르고, 저장 v3 자원 허용 목록에 세 종을 추가한다. 기존 데이터는 그대로 유지.
- 바구니/수종 판재/기존 17개 제작법 및 전 단계 부산물 가공은 변경하지 않는다.
- **천과 돗자리는 현재 제작 가능한 인벤토리 아이템**이다. 장착 효과, 가구 배치, 보온 효과를 새로 주장하지 않는다.
- 같은 방적 레시피에 서로 다른 식물 섬유가 들어간다는 사실을 테스트한다. 완성품의 실제 원료 이름·수량을 보여주는 표시 기능은 05-N 준비 작업으로 남긴다.
- 실제 식물의 안전한 식용·약효는 별도 검증 전 새 레시피에 반영하지 않는다.
