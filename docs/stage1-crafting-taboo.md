# Stage I — 제작 금기 판정의 한정적 도입

2026-10-28, 통합 로드맵 1단계 진행 중.

## 출처 신뢰와 판정 범위
- '칼두르' 관련 금기는 **이질 기원(alien) 소재를 이용해 장비를 제작하는 경우만** 해당한다. 여기서는 기존 장비 식별자 `tool05a:` 또는 서버 소유 레시피의 `equipmentOutput:true`에 대해 실행 전에 거절한다.
- `originClass`는 게임 코드가 관리하는 **정적 재료 정의**에서만 읽는다. 사용자가 명령에 포함한 출처 태그나 아이템 condition의 임의 값으로는 금기를 만들거나 해제하지 않는다.
- 신성 수목 **벌목**과 신성 수생생물 **포획/살해**는 각각 나중에 해당 획득 행동의 판정 지점에서 처리한다. 제작 처리기에서 신성/몽환/공허 소재 전체를 금지하지 않는다.
- 정확 ID 슬롯과 범용 재료 슬롯 **양쪽 모두** 실제 배분 이후에 판정하므로 특수 소재의 우회 장비 제작을 막는 구조다.
- 이질 소재 정의와 직접 획득 경로를 새로 만들지 않는다. 정적 정의가 아직 없으면 임의 출처를 추론하거나 실제 시스템에 소급 적용하지 않는다.
- 영회 재료 소모/턴 소비는 기존 제작 실패 계약을 따름. 저장 v3 변경 없음.

## 잔여 작업
이 PR은 제한된 제작 금기의 기반 구현이다. 실제 특수 소재가 등록될 때 정식 sourceId->itemDefinitionId 기원 매핑과 정의 검증, 장비 대상 범위의 목록화, 금기 사전 안내 및 이벤트 처리가 필요하다. 아직 스테이지 I 완료가 아니다.
