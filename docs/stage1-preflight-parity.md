# Stage I — 제작 화면의 실행 전 검증 일치

UI가 재료 1회분만 확인하고 반복 제작 수량 및 생존 제한에 대해 '제작 가능'이라고 잘못 표시하던 경로를 제거했다. `previewWorkshopActionStage1`은 활성 제작법과 서버 정의를 사용해 작업대 접근, 생존 임계치, 선택한 스택, 재료 부족, 반복 중단 시간, 금기를 종합 평가한다. UI와 실제 명령은 같은 `craftBatch1`/`craftUntilStage1`을 호출하며, 미리보기는 원본 상태를 수정하지 않는다.

화면에는 완료 예상 횟수와 중단 이유를 표시하고 생존 안전 설정 변경에도 즉시 재평가한다. 생존 변화 기본 소모율은 0이며 제작 중 실시간 사용자 취소·백그라운드 생산 기능은 여전히 없다. 이 변경을 Stage I 전체 완료로 기록하지 않는다.
