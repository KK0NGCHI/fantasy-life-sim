# Stage I: 제작 완료 경계 생존 상태 전이 (2026-10-28)

장기 제작 행동의 경계를 **개별 제품 완료 시점**으로 정한다. `craft.until`은 완료 후 상태를 갱신하고, 다음 회차 시작 전에 설정한 HP/MP/허기 하한을 검사한다. 완료한 작업만 재고·턴·시간·상태 변화에 반영된다.

**중요:** 기존 게임 디자인에는 작업 시간별 HP/MP/허기 변화율이 명세되지 않았다. 그래서 제작 기본값은 **0 변화**이며, `survivalDelta`는 실행 시 명시되는 항목당 감소량(양수/증가는 허용하지 않음)이다. 임시 파라미터이며 플레이어가 임의로 능력치를 회복하는 경로가 아니다. 새로운 영구 저장 필드/상수/종족 대사 규칙을 추가하지 않는다.

코어의 현재 시간 경과 계약은 제작 후 경과 초를 일괄 반영한다. 이번 작업은 20회 이내의 완료 경계를 시뮬레이션하여 중단 수량·상태를 확정하지만, 전투·상태이상·NPC·환경 피해 사건이 매 제작 사이에 끼어드는 완전한 이벤트 큐나 백그라운드 비동기 작업은 구현하지 않는다.

남은 완료 게이트는 승인된 시간 기반 생존 변화 규칙의 실제 게임 전반 적용, 정식 이질 기원 자원 획득 경로, 주거/도구 기반 설비의 확장 및 사람의 브라우저 UI 검수다.
