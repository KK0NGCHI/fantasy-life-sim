# 05-E 광물 안정화 — 채광 경로 통합

## 확인 및 수정한 결함

1. **곡괭이 경도 제한 우회**: 신규 `mineral.extract` 명령은 보유한 곡괭이 유무만 확인하고, 모든 채굴에 고정 능력치 3을 적용했습니다. 기본 석재 곡괭이로도 철광석의 경도 3을 통과할 수 있었습니다. 이제 실제 인벤토리에서 소유권이 확인된 곡괭이의 검증된 등급(기본 1, 구리 2, 철 3, 강철 4)으로만 채광합니다. 명령의 `toolPower`는 사용하지 않습니다.
2. **별도 광맥을 이용한 중복 수급**: 종전 `resource.work` 채광과 신규 `mineral.extract` 채굴은 같은 광물의 잔량을 서로 다른 장부에서 관리했습니다. 이제 신규 광물 모드가 활성화된 세계에서, 기존 채광에 성공해 나온 광물 수량도 같은 지역의 신규 유한 매장량에서 차감합니다. 잔량이 부족하면 행동이 거부되고 보상은 지급되지 않습니다. 기존 광물 모드를 사용하지 않는 세계에서는 종전 규칙을 유지합니다.

## 유지하는 규칙

- 광맥의 장기적 자연 재생 없음
- 지역과 발견 상태, 매장량, 품위는 저장 v3의 권위 있는 세계 상태
- 약한 도구·잘못된 지역·고갈 광맥은 보상과 시간 상태를 바꾸지 않고 거부
- 품위/매장량 수치는 임시 게임 밸런스이며 새 광맥의 생성·탐사 확장은 별도 설계

## 향후 검증 및 통합

- 기존 자원 노드의 채광과 05-E 전용 광맥은 **공유 매장량을 소비**하지만, 노드의 구별된 상태(발견 여부, 진행률 등)는 여전히 별도로 관리합니다. 단일 광맥 ID와 지층 좌표로 병합한 것은 아닙니다.
- 자동 탐색/채광이 양쪽 명령을 혼용할 때 수급과 중단 정책을 검증해야 합니다.
- 게임 UI에는 05-E 광맥 전용 패널과 거부 이유, 실제 도구 등급 표시가 아직 없습니다. 플레이 가능한 UI를 제공했다고 주장하지 않습니다.
