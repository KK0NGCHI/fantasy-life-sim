# Somnium 자원 마스터 설계 v0.5 — 원천·획득물·가공·제작 관계

> 2026-10-27. 사용자 승인: 현실/판타지 자원 병행 + 종별 고유 아이템 + 범용 재료 호환 + 역할별 속성 전승. 이 문서의 **구조 원칙은 채택**, 신규 종·판타지 소재·레시피 세부값은 **검토 후보**. 전체 콘텐츠 구현 완료를 뜻하지 않는다.

**중요:** 384는 지역별 배치 수이고, 348은 이름 병합 결과이며, 539는 획득물 부위 후보입니다. 348종의 생물이나 539개 구현 아이템으로 표현하지 않는다. **v0.3의 원천·지역·획득물·활용 문구 이관은 완료**했지만 원본 Markdown의 전체 설명·레퍼런스는 Git 원문으로 이전되지 않았다. v0.3 자료의 원본은 별도 대화 첨부 파일.

## 식별자 규칙
1. sourceId는 종/광상/유물/관찰 대상 하나를 가리킨다. **동일한 종의 복수 지역 출현**은 여러 habitat 프로필로 나타낸다. 광상과 광물종은 다르게 식별해야 한다.
2. itemDefinitionId는 종에서 실제 획득하는 부위나 산물을 뜻한다. 수피·목재·도토리 등은 각각 별도 정의 가능하다.
3. processedDefinitionId는 판재·주괴·섬유 등 가공된 형태를 뜻한다. 종별 차이와 원재료 출처는 가공 후에도 기록한다.
4. recipeId는 재료 슬롯별 정확 ID 또는 family/form/grade/traits/출처 조건, 사용 수량, 재료 역할을 정의한다.
5. itemInstance는 재료 혼합 비율/원천/속성/금기를 판단할 수 있는 materialManifest를 보존한다. 서로 다른 물성 인스턴스를 무조건 합치지 않는다.

## 기존 코드와 마스터 데이터 병행
- src/resource-catalog-05a.js: 일부 채집 자원/기초 산물 정의와 후보 목록.
- src/resources-05a.js: 실제 자원 작업/지점 회복/도구 조건.
- src/fungal-ecology-05b.js: 균류 생태와 채집.
- src/mineral-atlas-05e.js: 다양한 현실 광물 후보 **도감 중심**.
- src/mineral-refining-05h.js: 05-H/I의 일부 제련·도구 제작 **실구현**.
- src/material-compatibility-05j.js: 정확 ID 및 범용 재료 슬롯의 **할당 가능성 판정 구현**. **재료 소비/완성품 지급/저장 변경은 아직 하지 않는다**.
- 기존 명칭을 새 source/item ID로 이중 등록하지 않는다. 광물종/광맥/인벤토리 광석 계층을 임의로 동일시하지 않는다.

## 대표 가공·제작 연결
| 작업 | 입력 슬롯 (수량은 시험 후보) | 출력 | 지위 |
|---|---|---|---|
| 판재 | 수종별 통나무 ×2 | 해당 수종 판재 ×2 | 참나무 판재 일부 05-H 유사 구현 |
| 밧줄 | 방적 가능한 식물 섬유 ×3 | 밧줄 ×1 | 기획 후보 |
| 의자 | 목재 판재 ×3 | 실제 수종 이력 있는 목제 의자 | 기획 후보 |
| 어망 | 밧줄 ×3 | 어망 ×1 | 기획 후보 |
| 구리 주괴 | 구리 제련 적합 원료 ×2 | 구리 주괴 ×1 | 기존 05-H 정확한 광석 ID 구현; 세부 광물 원료 매핑 보류 |
| 청동 | 구리 주괴 ×2 + 주석 주괴 ×1 | 청동 주괴 ×2 | 기존 05-H 구현 |
| 곡괭이 | 정해진 금속 주괴 ×2 + 다듬은 석재 ×1 | 금속 곡괭이 | 기존 05-I 금속별 정확 ID 구현 |
| 빵 | 확인된 식재료 가루 ×2 + 물 ×1 | 빵 ×1 | 기획 후보, 식용 여부 미검증 자동 허용 금지 |
| 조개 가공 | 패각 ×2 | 패각 분말 ×1 | 기획 후보 |
| 관찰 기록 | 관찰 대상 | 도감 지식 | 아이템 지급/소비 없는 행동 후보 |

56개 전체는 [제작 후보 원장](./resource-recipes-v05.tsv)에 있다. 모든 활용 관계를 실제 recipeId로 강제 확정한 것은 아니다. [기술 계약](./resource-crafting-contract-v05.md)은 역할별 속성 전승·실패 원자성·자동/수동 일관성을 규정한다.

## 불변 규칙
- 인벤토리 음식은 부패하지 않음. 밭에 남겨 둔 과숙 작물 부패는 별개.
- 축산 일반 산물 정확히 우유/고기/가죽/양털/알 5종. 몬스터 특수 부산물 별도.
- 식성은 초식·육식·잡식(골렘 포함)·이질식 4종, 이질식 사료 레시피는 하나.
- 신성 수목 벌목/신성 수생 포획·살해/이질적 출처 소재 장비 제작은 각각 베르단/네레이아/칼두르의 정확한 금기 조건에만 연결. 일반 자원 행위로 확대 금지.
- 16개 기본 지역에 깊은 숲·심층 광산·심해·심층 미궁의 구분. 심해는 일반 어업의 숙련 확장만으로 들어가지 않는다.

## 구현 전 남은 콘텐츠 정제
1. 348개의 잠정 이름 병합 결과를 실제 종·광상·시설·유물·관찰 대상으로 구별하고 별명/중복을 전수 검토.
2. 539개의 잠정 부위를 **안정적인** 정식 itemDefinitionId, family, form, usable/observation-only, 독성·식용 확인과 연결.
3. 56개 가공·제작 후보의 정확한 입출력·가공 설비·부위별 호환·역할·전승 규칙·시간·수량·실획득 경로 확정.
4. 종별 출처/특성을 실제 아이템 인스턴스에 보존하는 저장 호환 및 이전 정책.
5. 도감·연구 전용 원천과 실제 채집/사육/벌목/낚시 보상을 구분하고, 위험 금기 사전 안내와 검증 강화.
