# 05-H · 가공 시설 및 청동 합금 1차 연결

- 정련/제련은 `거점 마을`의 공용 작업대·용광로에서만 실행된다. 시설은 장소 서비스로 간주하며 소유물·건설물 저장 필드는 아직 없다.
- 기존 구리/철/주석 주괴·석재·점토 가공 5종을 유지한다.
- 청동 합금은 **구리 주괴 2 + 주석 주괴 1 → 청동 주괴 2**의 임시 게임 밸런스로 도입한다(900초).
- 투입물 모두의 **실제 인벤토리 소유권과 수량**을 먼저 검사한 뒤 하나의 아이템 상태 갱신으로 소비·생성한다. 부족하면 전부 거부하고 소모하지 않는다.
- `자원 활동 → 채광` 화면에 가공 레시피와 현재 보유량·필요량·가공 버튼을 표시한다. 마을 외에서는 비활성화한다.
- 저장 v3 구조를 유지하고 광맥 모델은 변경하지 않는다.

제약: 용광로 연료, 온도, 시설 건설, 실제 합금 조성 및 레시피 대량 확장은 후속 생활 제작 단계에서 검토한다. 현재 청동의 재료 비율은 실제 제련/합금 표준이 아니라 임시 게임 규칙이다.
