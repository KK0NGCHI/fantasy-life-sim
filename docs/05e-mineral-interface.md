# 05-E 광맥 UI·상호작용 연결

## 이번에 구현한 경로
- 신규 게임 세션에서 05-E 유한 광맥 상태를 활성화합니다.
- 광산/산맥의 생활 → 자원 활동에 **광물 탐사 · 유한 매장층** 패널을 표시합니다.
- 탐사되지 않은 광맥은 종류별 `mineral.prospect`로 600 게임초를 소비하여 발견합니다.
- 발견된 광맥은 남은 재고·초기 재고, 품위, 경도, 현재 보유한 곡괭이의 능력을 표시합니다.
- `mineral.extract`로 180 게임초를 소비하여 채굴하며 획득 0개도 정상 판정으로 표시합니다. 실제 재고는 항상 감소하며 게임 상태를 다시 읽어 화면에 반영합니다.
- 곡괭이 등급 미달·매장량 고갈이면 채굴 버튼은 비활성화됩니다. 서버 역할의 엔진 역시 독립적으로 제한을 검증합니다.
- 기존 05-A 자원 작업과 05-E 유한 광맥 채굴은 #68부터 동일한 지역 매장량을 소비합니다.

## 검증
`tests/browser-05e-mineral.mjs`을 Chromium CI에 연결했습니다. 실제 월드맵 이동 후 철 광맥 발견, 기본 곡괭이의 철 채굴 비활성화, 돌 광맥 발견 및 1회 채굴, 잔량 16→15 갱신을 검사합니다.
