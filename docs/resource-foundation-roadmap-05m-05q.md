## 사용자 결정: 제작 재료 표시의 최소화
- 완성품 상세에서 **실제 사용한 재료의 이름과 수량**을 확인할 수 있어야 한다. '참나무 판재×2 + 풀섬유 밧줄×1' 등.
- 모든 이전 단계의 원천·채집 장소·제작 시각을 추적하는 복잡한 이력 시스템은 도입하지 않는다.
- 단, 신성/이질 기원 등 금기 판정에 직접 필요한 명시적 정보와 종별 호환·물성은 보존한다.
- 서로 다른 재료 구성의 완성품을 중첩할지 여부는 재료 표시를 잃지 않는 정체성/저장 규칙을 정한 뒤 결정한다. 구형 save v3의 무단 변환 금지.

## 콘텐츠 확장 전략
새 자원을 일괄 등록하지 말고, 원천 → 발견/획득 → 부위별 아이템 → 가공 중간재 → 실제 제작 또는 연구/도감 활용 → 저장/불러오기를 하나의 묶음으로 완성한다. 신규 항목은 `definition-exists`, `discoverable`, `obtainable`, `processible`, `craft-usable`, `ui-visible`, `save-tested` 등으로 상태를 분리한다.

## 05-M: 숲·식물·섬유
- 수종별 원천: 기존 참나무에 소나무·자작나무·버드나무를 우선 추가 대상으로 검증. 같은 수목의 벌목(통나무)과 비파괴 채집(가지·수피·수액·열매)을 구분한다.
- 들풀·갈대·아마·쐐기풀 등 섬유 원천을 1차로 정리해 통합 `plant-fiber` 재료군의 종류별 가공 적합성을 검증한다.
- 판재·수지·목탄·밧줄·실·천·엮음재 중 실제 획득 경로가 확인된 것부터 제작 체인 개통.
- 최소 2종 서로 다른 목재 판재가 같은 범용 레시피에 투입되는 검증, 각각 실제 사용 재료 표시, 금기 조건 사전 고지.

## 05-N: 목공·직조·공통 제작
- 작업대별 레시피 가용성 및 제작법 목록, 대체 재료 선택, 부족 재료 설명, 연속/자동 제작의 동일 판정기 사용.
- 가구/상자/바구니/도구/직물/액자 등 **제작 가능한 아이템**부터 확장. 배치·보관 기능은 별도 생활 시스템으로 분리하여 거짓 기능 암시 금지.
- 완성품의 최소 재료 구성 정보를 아이템 상세에 표시. 중첩/개별화·save v3 호환·구형 슬롯 불변 테스트를 통과하기 전 저장 구조를 바꾸지 않는다.

## 05-O: 광물·석재·금속
- `05-E` 광물 도감의 광물종과 광상/광맥을 분리. 중복 채굴 원장·중복 재고 지급 금지.
- 실제 채광 경로 → 광물별 선광/정련 → 주괴/판석/벽돌/연마 보석 → 도구·장식 제작으로 닫힌 루프를 만든다.
- 기존 05-H/I 제련·도구 레시피의 입력 수량·시간·결과·세이브 회귀를 지속 검사한다.

## 05-P: 어업·수생 자원
- 강·호수, 해안, 바다와 별도 심해를 구별한다. 낚시 숙련만으로 심해 입장 불가.
- 어류·패류·갑각류·해조류·잡동사니/유물 인양을 실제 획득 경로로 연결한다.
- 어육 손질, 먹물/안료, 패각 세공 등 제작 기반 가공까지만 확장. 고도화된 요리·경제·주거 시스템은 이후.
- 신성 수생 생물 포획·살해에 한해서만 네레이아의 금기를 고려한다.

## 05-Q: 생태·도감·품질 검증
- 지역·계절·서식·재생·희귀도·심화 구역을 근거 있는 정의로 연결한다. 실제 독성/식용성 검토 전 요리 가능으로 간주하지 않는다.
- 판타지종은 이름과 속성의 세계관 적합성을 승인받고 금기/출처 판정을 일관되게 적용.
- 길게 반복되는 채집·제작, 재료 부족·자원 고갈 시 안전 중단, 저장/불러오기, Windows/Chromium/엔진 통합 테스트.

## 각 단계의 완료 게이트
1. 콘텐츠 설계(정식 ID/원천-부위 관계/획득조건/사용처/레시피/공정/예외/시간 후보) 문서화.
2. 구현은 검증 가능한 작은 브랜치·PR로 진행하고, 사용자 승인 불변식·기존 저장 데이터 보호.
3. 최소 하나의 실제 획득부터 소비/생산까지 엔드투엔드 테스트. 상태 변경 없는 거절·중복 재고 소비 방지.
4. 실제 UI에 표시되고 저장/불러오기가 가능하며 엔진·Windows·Chromium 검사를 통과해야 '구현 완료'.
5. 각 단계 뒤 자원 소비처 고립 항목·정식 ID 중복·도감-only 항목·미구현 기능 표시를 검토.

## 금지·제약
- 모든 348개 잠정 원천이나 539개 부위를 일괄 활성화했다고 주장하지 않는다.
- 축산물 일반 범주는 우유/고기/가죽/양털/알 5개, 식성은 초식/육식/잡식(골렘 포함)/이질식 4개, 이질식 사료 레시피 하나.
- 인벤토리 식품은 부패하지 않는다. 신성 나무 벌목·신성 수생 포획·이질 기원 장비 제작의 금기는 정확한 대상/행동에 한정한다.
- 세계관/게임플레이 설계와 프로그램 명세에서 확정되지 않은 수치를 임의로 상수화하지 않는다.
