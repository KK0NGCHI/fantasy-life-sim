# 인터페이스 v0.2 — 레퍼런스 기반 개편 기록 (2026-10-22)

## 확인한 레퍼런스: 사실과 적용안 구분

| 자료 | 자료에서 확인한 내용 | 본 프로젝트에서의 적용안 |
|---|---|---|
| [RimWorld UI](https://rimworldwiki.com/wiki/User_interface) | 화면 하단 기능 메뉴와 선택 대상 Inspect 패널, 항목별 자원 목록 | 사이드 글로벌 내비게이션과 목록 옆 상세 패널 분리 |
| [RimWorld Architect](https://rimworldwiki.com/wiki/Architect) | 건축 및 생산 작업을 성격별 하위 메뉴로 나눔 | 생활 활동/제작/생산 기록을 작업별 하위 탭으로 분리 |
| [Stardew Valley Player Menu](https://wiki.stardewvalley.net/Player_Menu) | 소지품, 숙련 등 정보를 탭으로 조직; 소지품 화면에 날짜와 자금 정보 포함 | 캐릭터·소지품·숙련을 기능별 하위 탭으로 분리하고 상단에 골드·시간을 배치 |
| [Stardew Valley Inventory](https://wiki.stardewvalley.net/Inventory) | 가방 및 핫바에서 아이템을 관리 | 초기에는 표 기반 아이템 검토, 핫바/칸 배치는 추후 검토 |
| [Carbon Data Table](https://www.carbondesignsystem.com/components/data-table/usage/) | 표 정렬, 필터, 다중 선택, 상세 펼치기, 일괄 액션 | 인벤토리 목업에서 종류 탭·정렬·검색·다중 선택·상세 패널 구현 |
| [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) | 본문 텍스트 명도 대비 4.5:1, 키보드 포커스 및 확대·리플로우 요건 | 의미별 다색 팔레트·focus-visible 및 반응형 레이아웃을 지향; 대비·실기기 검사 전 |

아직 직접 확인하지 않은 원작의 내부 구현, 스킬 공식, 아이템 계수 등은 이 문서에서 사실로 주장하지 않습니다.

## v0.2 디자인 결정 (확정 아님)

- 밝은 흰색/연한 녹색 기반, 녹색 생활, 청색 탐험, 황색 재화/주의, 적색 위험, 자주색 마법 계열의 의미 색
- 상단: HP, MP, 허기, 재화 **예시 수치**, 날짜·시간 **예시**, EXP 미정, 상태 이상
- 좌측: 글로벌 메뉴 및 하단 단축키 유지. 공간을 불필요한 카드로 나누지 않음
- 중앙: 화면별 명시적 탭과 대상 상세 정보 분리
- 우측: 검색, 유형 필터, 연속 반복 묶음, 중요 기록 고정, 세부 정보. 기본 로그에 T1 같은 턴 번호 제거
- 행동 문구: '~다'에서 '낚시', '작물 수확', '채광', '밭 돌보기' 등의 명사구로 변경
- 아이콘: 유니코드 도형 기호 기반의 임시 표식. 최종 그래픽이나 픽토그램 시스템은 아직 미정

## 남은 검증 항목

- 브라우저에서 1366×768, 1920×1080, 좁은 화면에서 스크롤/정보량 검사
- 한글 자간/행간, 키보드 전용 조작, 실제 대비비 검사
- 로그가 500건에 근접할 때 반응성
- 장시간 아이템 목록 렌더링 성능 및 상세 패널 처리
- 종족·직업·아이템 스키마와 UI 표시 필드의 관계를 실제 콘텐츠 데이터로 검증

실제 게임의 성장, 경제, 랜덤 던전, 제작 계산 등은 이번 UI 변경에서 확정하지 않았습니다.
