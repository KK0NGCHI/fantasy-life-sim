# 05-G · 광상 복수 광물 원자적 채굴 (보수적 첫 구현)

## 범위
- `mineral.assemblage.extract` 엔진 명령은 **동일한 광상 유형**의 발견된 광맥 2~3개를 묶어 채굴한다.
- `src/mineral-extraction-05g.js`의 `extractAssemblage05G`가 모든 site ID, 지역, 발견 여부, 고갈, 실제 도구 등급, 광상 동일성을 **먼저 검증**한다. 하나라도 실패하면 어느 원장도 차감하지 않는다.
- 각 자원은 **자기 광맥 재고에서 정확히 1개씩** 차감한다. 광상 그룹에는 독립적인 소비 재고가 없다.
- 임시 수율은 기존 05-E 채굴 수율(품위 및 난수)과 동일한 단일 난수 입력을 사용하며, 한 명령 안의 결과를 한 번에 커밋한다. 미산출이어도 해당 광맥 재고 차감은 기존 규칙과 같다.
- 플레이어 도구의 실제 인벤토리 소유권/등급을 검증하며, payload의 임의 도구 등급을 신뢰하지 않는다.
- 기존 단일 `mineral.extract` 명령과 저장 v3 스키마는 유지한다.
- 채광 시간이 1턴/게임 시간 180초인 실험 명령이다. 본격적인 다광물 밸런스 확정 전까지 임시값이다.
- **열수 광상 실험을 시작으로**, 동일한 범용 처리기가 퇴적·증발암·관입암·화산암·변성암 등 다른 광상에도 적용된다. 광물별로 복잡한 보상 공식을 복제하지 않는다.

## 한계와 후속 안전 게이트
- 광상 구성은 지금도 광물별 분리 광맥의 연결 관계다. 실제 지질적으로 동일한 물리 광체/광석 조성을 구현한 것은 아니다.
- 사용자 UI에는 복수 광물 채굴 버튼을 아직 노출하지 않는다. 엔진 명령과 테스트 단계이며 자동 채굴 루프에서도 기본 동작을 바꾸지 않는다.
- 하나의 난수로 산출 판정하므로 2~3광물 산출 결과가 상관된다. 광상별 독립 난수/분배율은 별도 밸런스 검증 후 도입할 것.
- 광물별 품위 1과 매장량 4의 임시값은 이전 단계에서 유지하며, 이 PR에서 변경하지 않는다.
- 과거 save-v3 변환이나 05-F 읽기 전용 sidecar 자동 승인/삽입을 수행하지 않는다.
- 실제 광맥 중 여러 광물의 공유 지질 기원/위치·부산물 생성·고갈-중단-재개 자동 채굴은 후속 PR.
- 임의의 `siteIds` 선택을 UI에 노출하기 전에 광상 내 동일 위치의 구성원인지 검증하는 추가 모델링이 필요하다.
