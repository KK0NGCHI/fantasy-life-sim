# 05-M 첫 구현: 자작나무·버드나무 벌목과 판재 가공

- 2026-10-27. 05-M 원천 확대 구현의 첫 제한된 단위.
- **추가 실체**: 숲 자작나무(`resource05a:birch-log`), 습지 버드나무(`resource05a:willow-log`). 각 node는 기존 05-A 벌목 동작·장비 요구·고갈/재생 규약을 재사용한다. 갯수·경험치·재생 값은 잠정 밸런스.
- 기존 `item05a:oak-log`, `item05a:pine-log`과 구분되는 신규 인벤토리 아이템 `item05a:birch-log`, `item05a:willow-log`을 원장에 등록.
- 작업대에서 수종별 통나무×2 → 수종별 판재×2 (`item05m:birch-planks`, `item05m:willow-planks`). 05-L 바구니 제작은 정확 ID 아닌 `processed_wood/plank/grade>=1` 조건을 사용하므로 세 판재 수종을 호환한다.
- 기존 05-H/I의 정확 17개 원본 목록을 유지하고, 신규 제작법은 `ALL_CRAFTING_RECIPES_05L` 통합 목록과 실행기/화면에만 추가했다.
- 이번 단위는 **벌목/가공 기능**만 실제 활성화한다. 수액·수피·가지 등 비파괴 부산물은 M1/M3 세부 노드/재생 계약 및 save v3 호환 규칙을 작성한 뒤 별도 PR에서 추가한다.
- 실제 소모 재료 이름/수량 표시는 후속 아이템 상세 기능이며 이번 단위에서는 미구현이다. 출처 전체 계보를 기록하는 시스템은 만들지 않는다.
- 판타지 수목·신성 수목의 금기는 이번 신규 일반 수목에 자동 부여하지 않는다.
