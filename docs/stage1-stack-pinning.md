# 통합 로드맵 I단계 — 스택 단위 제작 재료 선택

2026-10-28. `choices`(재료 종류 선택)와 독립된 `stackChoices`(인벤토리 스택 ID 선택)를 추가했다. 범용 레시피 슬롯에서 **소유한 스택을 지정**할 수 있다.

- 지정 스택은 신뢰하지 않는 사용자 입력이며 소유권·아이템 정의·재료군·형태·등급·재료 종류 선택을 **서버 측 05-J 할당기**에서 동시 판정한다.
- 특정 스택은 **해당 슬롯의 필요 수량 전체를 충족**해야 한다. 여러 스택 사이에서 분할 배분하려면 자동 선택 모드로 둔다.
- 기존 `craft.batch`, `craft.until`에서 직접 선택을 동일하게 적용한다. 선택된 스택 고갈 시 다른 스택으로 자동 전환하지 않는다.
- 사용자는 UI에서 재료 종류 자동/고정과 보유 스택 자동/고정을 각각 선택할 수 있다. 횟수 선택 시 재고 부족은 기존 정책(전량 취소/부분 완료)과 동일하다.
- 기존 인벤토리 항목, save v3 형식, 05-H/I 원래 제작법은 변경하지 않는다. 선택 사항은 각 제작 명령 payload에만 존재하고 저장 필드는 추가하지 않는다.
- 1단계 잔여: 현실 출처/신성·이질 금기 연결, 긴 자동 작업 안전 중단 정책, 작업대/도구 필요조건 확대, UI 장기 수동 검증.
