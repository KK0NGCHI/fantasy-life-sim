# Stage I — 반복 제작 시간 상한

craft.until은 선택적 policy.maxSeconds (1~86400 게임 초)를 받습니다. 온전히 끝낼 수 있는 제작만 실행하고 시간 한도에 도달하면 TIME_BUDGET_REACHED로 중단합니다. 성공분만 재고와 턴, 시간에 반영합니다. 수행 가능한 작업이 0회면 0턴 실패입니다. 기존 craft.batch의 전량 성공/전량 취소 계약은 그대로 유지합니다.

UI는 무제한, 10분, 30분, 1시간(게임 내 시간)을 제공합니다. 이는 한 번의 명령 내 동기 처리이므로 실시간 백그라운드 작업이나 실시간 취소는 제공하지 않습니다. save v3 형식은 변경하지 않습니다. 단계 I 마감 전에는 실제 특수 원천과 금기 연결, 도구/설비, 최종 장기 플레이 검증이 남았습니다.
