# Somnium 자원 설계 및 구현 진행 안내 (2026-10-27)

**최신 개발 방향:** [05-M~05-Q 자원·제작 기반 완성 로드맵](./resource-foundation-roadmap-05m-05q.md). 05-J/K/L은 이미 구현·병합되었으며, 완성품에 실제 사용한 재료·수량만 표시하는 최소 구성 정보로 설계를 단순화한다. 생활 시스템은 기반 완성 이후 확장한다.

> **현재 상태: v0.5 후보 마스터 정리 / 05-J 핵심 판정기 구현 완료 / 전체 자원 콘텐츠 구현 미완료.**
> 다른 세션에서는 이 파일을 먼저 읽고, 검토 대상 자원 후보를 세계관 확정 항목이나 플레이 가능 콘텐츠로 오인하지 않는다.

## 신뢰할 기준
1. [v0.5 자원 마스터 명세](./resource-master-v05.md): 데이터 수준, 중복 기준, 제작 후보, 남은 검토.
2. [잠정 원천 마스터 348개](./resource-master-v05.tsv): **384개 지역별 원천 배치**를 이름 기반으로 합친 잠정 수치. 실 고유 생물 종수 아님.
3. [384개 지역별 획득·활용 관계](./resource-edges-v05.tsv): v0.3에서 256행, v0.4에서 128행. 두 차수의 획득물과 활용 문구 이관 완료. 일부 가공 공정은 아직 검토 상태.
4. [부위별 획득물 후보 539개](./resource-item-parts-v05.tsv) / [부위별 레시피 후보 링크](./resource-item-recipe-links-v05.tsv): 부위 ID와 분류는 잠정. 원천에 따라 다른 '껍질' 등은 재검증 필요.
5. [제작·가공 후보 56개](./resource-recipes-v05.tsv) / [원천별 제작 계통 연결 384행](./resource-recipe-mapping-v05.tsv): **설계 후보**이며 정확한 아이템 ID가 연결된 실행 가능한 완성 레시피 56종을 뜻하지 않는다.
6. [재료 호환·출처·속성 전승 계약](./resource-crafting-contract-v05.md): 채택된 구조 원칙과 구현 전 검증 조건.

## 기존 기획 자료의 위치
- v0.3: 2026-10-27 작성된 지역별 256항목 원문은 이 대화에 업로드된 독립 Markdown이었다. **원문 전체를 Git에 그대로 올린 것은 아니지만**, 핵심 원천·지역·획득물·활용 행은 위 384행 관계표에 복원했다.
- [v0.4 추가분 128개 문서](./resource-design-v0.4-expansion.md)와 [원본 관계표](./resource-relations-v04.tsv)는 Git에서 그대로 볼 수 있다.
- 기존 구현과의 정합성: src/resource-catalog-05a.js, src/resources-05a.js, src/fungal-ecology-05b.js, src/mineral-atlas-05e.js, src/mineral-refining-05h.js. 정의 존재 ≠ 실제 획득 가능 ≠ 실제 레시피 실행 가능.

## 기술 구현 진행 상태
- [05-J 재료 호환 구현 상태](./05j-material-compatibility-implementation.md): src/material-compatibility-05j.js의 정확 ID/범용 family·form·grade·태그·출처 판정과 중복 소비 없는 슬롯 할당 계획기 **구현 및 자동 검사 통과** (PR #130).
- **미구현 범위:** 539개 부위의 전체 실제 지급 및 56개 후보 제작법 전체 실행, 완성품의 실제 투입 재료 표시/저장, 자동 제작. 단, 05-K는 재료 소비·결과물 지급에 통합됐고 05-L에서는 밧줄·바구니 신규 제작 루프가 실제 제작 탭에 연결됐다.
- 구현 후반부는 정식 itemDefinitionId 매핑, 출처/성질 규칙 정제, 실패 원자성·저장 이전 테스트가 선행되어야 한다. 시험값을 확정 밸런스처럼 취급하지 않는다.

## 유지할 사용자 결정
- 현실/판타지 자원 병행, 종별 정체성 유지, 재료군에 의한 범용 제작 호환, 역할에 맞는 속성 전승.
- 16 기본 지역과 깊은 숲/심층 광산/심해/심층 미궁. 심해는 낚시 숙련도만으로 진입하지 않음.
- 인벤토리 음식 불부패, 밭 과숙은 부패 가능, 수목 비파괴 채집과 벌목 구별.
- 일반 축산 산물은 우유·고기·가죽·양털·알 정확히 5종. 식성 4종(골렘 잡식, 이질식 사료는 하나).
- 베르단 금기=신성 수목 벌목, 네레이아 금기=신성 수생 생물 포획·살해, 칼두르 금기=이질적 기원 소재로 장비 제작. 출처와 지역을 혼동하지 않음.
