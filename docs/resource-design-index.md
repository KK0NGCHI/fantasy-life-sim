2. [v0.4 대응 관계표 TSV](./resource-relations-v04.tsv): 128행의 기계 가독 관계표. rowId는 임시 참조용이며 실제 sourceId/itemId 아님.

## 기준 문서의 관계
- **v0.3**: 2026-10-27에 별도 작성된 지역별 **256개 배치** 설계 초안. 현재 Git에는 원문 전체가 아직 반영되지 않았다. 작업자는 이를 Git에 존재한다고 추정하거나, v0.4의 128행이 그 전부라고 오인해서는 안 된다.
- **v0.4**: 그 위에 **128개 지역별 후보**를 추가했다. 합산 **384개 지역 배치 후보**이며 고유 종수나 구현 종수가 아니다. 현실 자원·가공 재료·유물·관찰 전용 원천이 혼재한다.
- 추후 **v0.5 통합 마스터**에서 v0.3 원문을 가져와 v0.4와 합치고, 중복/실 ID를 정리한다. v0.5 검수와 사용자 승인이 끝날 때까지 런타임 자료에 신규 후보를 대량 반영하지 않는다.

## 확정 불변식
종별 정체성 보존 + 재료군 범용 제작 호환, 원재료 출처·가공 역할별 속성 전승, 축산 산물 정확히 5종, 식성 정확히 4종, 인벤토리 식품 부패 없음, 신성 수목/수생 생물/이질적 기원 장비 소재에 대한 각 신 금기 조건 구별.

## 다음 세션 작업 순서
1. v0.3 원본을 확보해 Git으로 옮긴 뒤 v0.4 128행과 통합한다.
2. 자원 원천·획득물·중간재·완제품을 서로 다른 ID로 정의하고 중복 원천/복수 지역 출현을 병합한다.
3. 획득 가능한지, 실제 소비되는지, 연구·전시 전용인지까지 관계 그래프를 검증한다.
4. 판타지 생물·신성·안전성·계절·서식 조건의 사용자 검토를 거친다.
5. 설계 승인 후에만 구현 브랜치를 시작한다.
