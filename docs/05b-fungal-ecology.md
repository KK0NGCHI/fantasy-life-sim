## 조사 근거
- UC IPM: 균사는 기질 속에서 지속되고 자실체는 조건이 맞을 때 나타납니다. 자실체 수확은 곧 균사체 제거를 의미하지 않습니다. https://ipm.ucanr.edu/home-and-landscape/mushrooms-in-lawns/
- Vintage Story: 버섯 생성은 강수량·온도·나무 서식과 관련하며 동일 지역에서 다시 발생합니다. https://wiki.vintagestory.at/index.php?title=Mushroom/en
- Don't Starve Together: 특정 시간대에 수확 가능하고 비에 의해 다시 자라는 자원 설계를 참고했습니다. https://dontstarve.wiki.gg/wiki/Mushrooms/DST

## 데이터 계약

## 공통 엔진과 차이
- 공통 `ecology-core-05a.js`의 지역별 개별 군락, 고갈, 저장, 시간, 산출물을 그대로 재사용합니다.
- 균류 전용 정책: `wetCredit`(잔여 강우일 누적), `fungalReconcile05B`(누적 비 오는 날에만 자실체 재생), `fungalFruiting05B`(최근 4일 강우와 제철 조건), `fungalHarvest05B`(자실체만 채집하고 균사체 군락 유지).
- 동작하는 발견 경로는 기존 지역 탐색의 `fungal` 등급군입니다. 직접 채집은 기존 `botanical.patch.harvest` 명령을 범용적으로 재사용합니다.
- 저장: `resource05A.ecologySites`에 선택적 `wetCredit` 값을 저장합니다. 저장 v3는 이를 범위 검증하며 기존 식물 패치 저장과 호환됩니다.
- 기존 식물 80종은 수정하지 않고 회귀 테스트로 유지합니다.

## 현재 의도된 한계
- 기질과 공생 유형은 프로필로 정의하지만 월드맵 나무·고사목 실제 좌표와 연결되지는 않았습니다. 균근 버섯의 생물학적 공생 관계를 시뮬레이션하는 것은 아닙니다.
- 자실체는 최근 비와 시즌으로만 판정합니다. 자실체의 개별 수명·부패, 포자 확산, 균사체 확장, 경쟁·감염·영양 흡수는 후속 단계입니다.
- 강우량은 공통의 게임용 지역 기후 모델로 결정하며, 실제 지역의 기후 관측치는 아닙니다.
- 채집한 균류를 실제 세계에서 식별하거나 섭취해도 된다는 의미는 결코 아닙니다.
- 조사와 품종 데이터 모두 기획 초안입니다. 신규 분류군 콘텐츠를 대량 추가하기 전에 균류 정책의 저장·재생·반복 판정 검증을 우선합니다.
