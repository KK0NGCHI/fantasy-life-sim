# 05-G 최소 광상 식별자 — 광맥 설계 범위 종료

이번 단계에서 명시적으로 허용한 복수 광물 묶음에 한해, 지역과 묶음 ID로부터 재현 가능한 `deposit05g:<region>:<cluster>` 식별자를 파생한다.

- 입력 site ID 순서와 무관하다. 지역이 다르면 광상 ID도 다르다.
- 기존 `mineralDeposits05E`의 모든 광물별 재고·발견 상태·저장 ID가 계속 권위 있는 원장이다.
- 실측 좌표·지층·심도·공유 매장량·랜덤 광상 스폰·추가 저장 필드는 **도입하지 않는다**.
- 임시 식별자는 동일한 물리 광체가 존재함을 증명하지 않는다. 실험용 묶음의 논리적 이름이다.
- 미확인 광물 조합이나 허위 site ID는 묶음으로 인정하지 않는다.
- 이번 범위 이후에는 광맥 구조 확대를 멈추고 채광 UX, 도구, 정련·제작 재료 연결, 수급 밸런스 등 플레이어 체감 시스템으로 넘어간다.
