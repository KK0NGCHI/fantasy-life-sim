# Somnium — 지역 활동·심층 필드·특수 지역 기획 (2026-10-23)

## 의사결정 상태
- **확정 (사용자)**: 광산은 던전이 아닌 **필드**. 탐색 숙련 + 지역 숙련으로 열리는 '깊은 숲(채집)', '심층 광산(채광)', '심해(낚시)'.
- **확정 (사용자)**: 위 심층 필드에는 **타일 탐색을 사용하지 않음**. 지역별 인카운터와 전투 가능. 화산·사막·설원 등 위험 필드에서도 전투 인카운터 가능. **모든 필드에 심층 필드를 일률 추가하지 않음**.
- **제안/세부 승인 대기**: 개방 수치·확률·아이템·전투 밸런스, 고대 유적과 폐허·묘지의 세부 활동 모델.
- 16개 광역 지역 존재 = 16개 타일 맵이라는 뜻 아님. 03-D 24×24 숲·미궁은 프로토타입이지 세계 룰을 고정하는 근거가 아님.

## 일반 필드
- 지역 기본 활동: 해당 지역 생산·생활·탐색 인터페이스. 탐색은 타일 이동과 별개.
- 탐색 + 지역 숙련 개방 규칙은 두 조건을 모두 요구한다. 수치 미정; 종속 위치/조건은 선언형 데이터로 보관.
- 심층 필드는 부모 필드 아래의 별도 활동 구역; 외부 세계의 16개 지역 수를 늘리지 않는다.
- 깊은 숲: 채집 전용 고급/희귀 자원·고유 발견·야생 인카운터.
- 심층 광산: 채광 전용 깊은 광맥·붕락/환경 리스크·몬스터 인카운터.
- 심해: 낚시 전용 대형/희귀 어종·환경 및 해양 인카운터. 실제 진입 표현(원정/조업)은 후속 UX 협의.
- 위험 필드(사막/설원/화산): 별도 심층 없이도 노출/준비도/장비/활동에 따라 인카운터가 발생할 수 있다.
- 모든 지역에 복제된 '깊은 OO' 추가 금지.

## 특수 지역 기능 구분: 제안
### 고대 유적 — 조사·해석·문명 지식
- 주된 행동: 흔적 관찰 -> 단서 수집 -> 해독/복원 -> 고대 기술·역사·제작 관련 지식의 영구 발견.
- 탐색/조사 및 후속 지식·제작 숙련이 보너스에 영향; 전투는 수호자/방어장치 등 제한적.
- 발견의 정체성은 유물과 지식. 지도/퍼즐은 선택적 인스턴스 방식이며 **영구 타일 던전으로 확정하지 않음**.
- 생성형 비밀 유적 지점은 발견형 `Site`로 모델링 가능; 퀘스트/전승과 연결하는 방향 검토.
### 폐허·묘지 — 수색·회수·위험 관리
- 주된 행동: 잔해 수색 -> 회수·정화/안전 조치 -> 물자·장비 부품·유품 획득 -> 사건/기록 단서 발견.
- 유적 대비 인카운터 위험도와 선택적 철수 판단을 강조. 망령/언데드는 세계관 승인 전 예시로만 취급.
- 보상의 정체성은 위험을 감수한 실물 회수, 드문 단서; 고대 유적의 문명 지식/해독과 중복 최소화.
- 묘지에서의 직접 약탈은 가치/평판/금기 등 세계관 설계가 필요하며 현재 결정하지 않음.
- 지도/전투 모드는 인카운터 기반을 기본 제안하며 **타일 던전으로 확정하지 않음**.

## 공통 인카운터 계약 (제안)
1. 활동 선택 -> 비용/조건 검증 -> 1회 활동 판정 -> 채집·발견·사건 또는 잠재적 적 조우 -> 조우 처리.
2. 전투는 '인카운터 이후 전투 시스템 진입'으로 분리. 환경 사건, 무해한 만남, 위험 조우가 모두 가능.
3. HP·MP·허기 자동 중단 정책을 유지하고, 위험 조우 전 자동 진행 일시정지.
4. 인카운터 확률과 숙련 공식/피해량은 이 문서에서 임의 확정하지 않음. 게임 내 시간은 중앙 dispatcher만 부여.
5. 이 문서는 행동 계약의 기획안이며, 위 기능의 UI·전투·보상 엔진은 구현되지 않았다.
