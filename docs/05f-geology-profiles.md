# 05-F · 지질 산출 환경 프로필 (1차)

## 적용 범위
- 현실 기반 도감 94개 모두에 `geologyProfile05F(materialId)` 조회 기능을 제공한다.
- 산출 환경은 화성암·관입암, 열수 광맥, 퇴적층, 증발암층, 변성대, 사광·풍화 퇴적, 화산암·화산활동, 미분류로 나눈다.
- 각 프로필은 **대표적 산출 환경의 예시**와 모암 예시·정성적 깊이 구간을 제공한다. 심도는 실제 미터 수치나 특정 지역에 배타적으로 존재한다는 뜻이 아니다.
- 분류가 불확실한 경우 **미분류**로 유지한다. 94종의 모든 산출 양상을 확정했다고 주장하지 않는다.
- 광산 UI에서 항목별 지질 참고 정보를 표시한다.

## 명시적인 비적용 범위
- 현재 기존 세계의 광산·산맥에 생성된 유한 광맥은 그대로 존재한다. **지질 환경 때문에 실제 게임 산출 지역이 바뀌지 않는다.**
- 매장량·품위·경도·채굴 확률은 PR #73 수치를 변경하지 않는다.
- 저장 파일에 새 지질 필드를 주입하지 않는다. 구버전 저장 마이그레이션도 변경하지 않는다.
- 창작/코스믹 16물질에 지질 출처를 강제로 부여하거나 채굴 가능 상태로 만들지 않는다.
- 광물종/원광/모암/광상 ID를 혼합하지 않는다.

## 후속 설계 우선순위
1. 각 후보 산출 환경의 검증/감수 및 복수 광상 허용 관계 정리.
2. 현실 광상의 산출 조합·모암·지역 지질 규칙을 별도 `deposit` 계층으로 모델링.
3. 기존 저장의 매장량 보존 및 세계 생성의 결정성 테스트.
4. 지층·깊이 접근 및 발견 장비·도구 요구의 밸런싱.
5. 가공·제련 및 부산물과 광석 품위 연결.
