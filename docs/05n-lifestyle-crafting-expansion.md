# Somnium 05-N 목공·직조 생활 제작품 첫 확대

2026-10-27 / 기존 원천·가공 아이템을 사용한 **콘텐츠 추가**. 새 원천이나 세이브 버전 변경은 없다.

## 실제 제작되는 6종
- 목재 스툴: 호환 판재×3, 풀섬유 밧줄×1
- 목재 선반: 호환 판재×4, 정제 송진×1
- 천 주머니: 식물성 천×2, 식물성 실×1
- 수피 책표지: 자작나무 수피판×2, 식물성 실×1
- 엮음 돗자리: 버드나무 엮음재×3, 식물성 실×2
- 송진 마감 목재 쟁반: 호환 판재×2, 정제 송진×1

모두 기존 거점 마을 작업대에서 `mineral.refine` 공유 실행기로 제작된다. 중복 재료 소모 방지를 위해 05-J 할당기를 사용한다. 05-N의 최소 재료 구성 표시 조건을 적용하므로 참나무/자작나무/버드나무 재료의 실제 사용 ID와 수량을 완제품에 기록한다. 서로 다른 재료 구성은 별도 재고 스택.

## 기능 경계
- 가구로 배치, 인벤토리 용량 확장, 착용, 효과, 세트 보너스 없음. 아직은 제작 가능한 인벤토리 아이템이다.
- 균사체, 신성/이질 재료와의 범용 대체는 허용하지 않음. 신뢰된 정적 정의의 목재 판재 `processed_wood/plank`만 유효.
- 기존 05-H/I 17개 레시피와 저장 v3를 유지. 각 제작 행동은 기존 1턴/작업대 시간 규칙 사용.
- 수치/시간과 완성품 종류는 첫 콘텐츠 슬라이스의 잠정 밸런스.
