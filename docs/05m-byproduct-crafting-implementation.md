# Somnium 05-M 부산물 가공과 활용 — 구현 단위

2026-10-27. 직전 PR #136에서 구현한 나무 부산물 획득을 실제 제작과 연결한다. 신규 자원과 별도 ID를 가진 가공품·완제품을 추가한다.

| 공정 | 입력 | 출력 | 설비 | 시간(시험값) |
|---|---|---|---|---:|
| 송진 정제 | 송진 2 | 정제 송진 1 | 작업대 | 300초 |
| 버드나무 가지 다듬기 | 버드나무 가지 2 | 엮음재 2 | 작업대 | 300초 |
| 자작나무 수피 가공 | 수피 2 | 수피판 1 | 작업대 | 300초 |
| 송진 방수 처리 | 기존 목재 바구니 1 + 정제 송진 1 | 송진 방수처리 바구니 1 | 작업대 | 600초 |
| 수피 안감 제작 | 기존 목재 바구니 1 + 수피판 1 + 엮음재 2 | 수피 안감 바구니 1 | 작업대 | 600초 |

## 구현 경계
- 기존 나무 4종의 비파괴 수확 ID에 직접 연결한다. 새 종, 새로운 수확 노드, save v3 필드 추가 없음.
- 기존 `REFINING_RECIPES_05H` 17개는 불변. 새 레시피는 `ALL_CRAFTING_RECIPES_05L` 통합 목록/기존 `mineral.refine` 경로에서 동작한다.
- 바구니 두 종류는 인벤토리의 **제작품**으로 등록된다. 물리 방수 성능, 보관함 사용, 주택 설치 기능은 아직 미구현. 명칭은 제작 방식의 설명이지 게임플레이 버프를 암시하지 않는다.
- 새 가공 아이템에 여러 원재료를 혼합한 모든 과거 경로를 추적하는 이력 시스템을 도입하지 않는다. 실제 사용 재료 표시 기능은 별도 05-N에서 다룬다.
- 수량·시간은 밸런스 확정 전 임시값. 현재 의도적인 다른 중간재 사용처는 추가 검토 대상.
## 회귀 기준
- 부산물 획득 ID → 새 중간재 → 바구니 2종의 실제 재료 차감·완성품 지급
- 잘못된 재료 및 부족 시 재고 불변, 레거시 17개 제작법 변경 없음
- 브라우저 제작 탭 표시, 엔진/Windows/Chromium 검사, 구형 세이브 유효성 유지
