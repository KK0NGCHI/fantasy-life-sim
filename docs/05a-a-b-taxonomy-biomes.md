# 05-A A/B: 자원 분류·지역 분포 첫 구현 (2026-10-24)
상태: **부가 데이터 카탈로그 + 테스트 구현**, 메인 게임 출현/채취·도감/품질 엔진 연결은 아직 **미구현**.

## 현재 결정과 경계
- 기본 분류에 자원종·산출물·환경 속성을 별도로 결합한다.
- 원본종(자원 source ID), 자원 지점(node), 획득물(item ID)을 구별하며 하나의 원본종에서 여러 산출물을 허용한다.
- 소재는 전역 고정 능력치 대신 종류·태그·제작법으로 결과 성능을 구별할 수 있게 한다. 제작 효과는 05-B 범위다.
- 출처와 성질 태그를 분리하고, 출처만으로 신성/외우주적 효과를 추론하지 않는다.
- 품질은 행동별 기본 정책 + 산출물 예외를 사용한다(구체 등급·수치 미정).
- 도감 등록은 실제 획득 성공 시점. 원본종이 있으면 해당 종과 얻은 산출물만 기록하고, 없는 일반 자원은 획득물 자체를 기록한다.
- 기존 12종의 ID·노드 생성·인벤토리·세이브 계약을 변경하지 않는다.
- 16개 지역은 모두 타일 맵이 아니며 일반 광산은 필드. 깊은 숲/심층 광산/심해/심층 미궁은 부모 지역의 하위 구역이다.

## 구현
- `src/resource-catalog-05a.js`: 16개 바이옴 자원군 정의, 4개 심화 구역의 부모 관계, 12개 기존 획득물 + 7개 검증 후보 획득물, 자원 원본종과 산출물 연결, 도감 획득 이벤트용 함수, 명시적 출처 태그 생성기.
- `tests/05a-catalog-biomes.test.mjs`: 분류·ID 무결성, 기존 12종과 호환, 복수 산출물, 출처 분리 테스트.
- 7개 추가 항목(블루베리, 참나무 수액, 수정 원석, 갈대, 홍합, 신성 참나무 통나무, 늪은방울버섯)은 검증 **후보**이며 새로운 정식 세계관 확정이 아니다.
- A-4 품질 규칙은 아직 보존 가능한 인벤토리 계약 및 제작 단계와 함께 구체화해야 하므로 이 작업에서 빈 수치를 창작하지 않는다.
