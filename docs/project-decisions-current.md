# Somnium — 현재 확정 규칙과 미확정 시험값

작성일: 2026-10-24. 이 문서는 기획의 현재 기준을 표시하며, 옛 01~04 문서를 소급 삭제하지 않는다. 결정을 뒤집거나 새 게임 규칙을 임의 확정하지 않는다.

## 사용자와 합의한 핵심 규칙 (고정)
- 브라우저 싱글플레이 판타지 생활 시뮬레이션; 정해진 필수 엔딩/클리어 목표가 없음. RP와 서로 다른 인생 경로를 중시.
- **전체 캐릭터 레벨 없음.** 개별 **54개 숙련(6계열)** + 기본 **7개 능력치**. 숙련의 일반 성장 기준은 30레벨이나 31 이상도 상승 가능하며 효율 상한을 둔다. 모든 숙련에 전문화를 억지로 넣지 않음.
- 16개 고정 광역 지역은 **16개의 타일 로컬 맵이 아님**. 미궁만 정식 타일 탐험. 숲 타일 생성기는 내부 프로토타입. 광산은 **필드**.
- 깊은 숲(탐색+채집), 심층 광산(탐색+채광), 심해(탐색+낚시)는 부모 필드의 **비타일** 활동이며 두 숙련 조건 충족이 필요. 고대 유적은 조사·해석, 폐허·묘지는 수색·회수·위험 관리로 구분.
- 행동 디스패처가 유효 행동의 턴 및 정수 초 단위 게임 시간을 부과. Day 1 08:00:00에서 시작. 기본 로컬 이동 6초, 벽 충돌 1턴 6초, 미궁 진입 10초, 생활 기본 60초, 무효 명령 0. 다만 개별 행동 시간 표는 명시적인 확장 설계에 따라 별도.
- 무게/휴대 용량 **없음**. 경갑/중갑은 완성 장비의 재질 및 제작 구조에 따른 범주; **방어구 종류와 신체 규격은 다른 속성**. 신체 크기는 보통/소형/초소형의 3단계지만 모든 종족이 **타일 한 칸 점유**, 타일 세분화 금지.
- 배경은 출발 숙련과 독점 권한을 부여. 다른 배경은 높은 일반 숙련만으로 **해당 배경 고유 능력을 획득하지 못함**. 종족·배경 때문에 캐릭터 전체 레벨이 생기거나 모든 숙련이 금지되지는 않음.
- 자동 행동과 직접 행동의 동일한 규칙·시간·XP 기준. 생존 자동 중단 임계값(HP·MP·허기) 지원. 임의 XP 농사 방지, 유효 결과 기반 지급.
- 퍼마데스 없음. 사망 페널티는 난이도별 후속 설계. 원본 저장 슬롯 무단 덮어쓰기/자동 이전 금지. 기존 v2/v3 데이터를 명시적 승인 없이 수정하지 않음.
- 배경 고유 능력의 추가 실물 콘텐츠(거래망, 제조법, NPC·사원)는 해당 기반 시스템 구축 **이후** 착수.

## 화면의 진위 구분
실제 동작: 광역 여행, 미궁 로컬 탐사, 발견 기록, 일부 세이브, 초기 능력치 배분, 출신 선택, 탐색 XP 일부, 배경의 일회성 정보 해석.
계획 또는 목업: 실제 농업·낚시·광업 자원 반복 루프, 가공/제작 경제, 전투 결과, 배경별 독점 레시피·거래/NPC 기능, 대부분의 숙련 XP, 특정 표시 골드/아이템 정보.
