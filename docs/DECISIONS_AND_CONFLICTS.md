- TypeScript 엔진/기존 JS UI, IndexedDB+외부 JSON 백업 방향, 시드 RNG, 저장 원본 보호. 무게 한도 없음, 영구 사망 없음.
- 인벤토리 식품 자동 부패 없음. **수확 적기를 놓친 밭 작물**은 부패 가능.
- 수목 벌목/비파괴 부산물 분리, 수중 생물과 심해 분리, 원천·재료 성질이 제작에 반영.
- 가축 식성 정확히 초식·육식·잡식·이질식(골렘=잡식), 이질식 사료 한 종류. 축산물 분류 정확히 우유·고기·가죽·털·알.
- 신성한 수목/수생 생물의 금기는 경고 후 의도적으로 위반 가능; 신앙/무신앙/개종 허용.
- 칼두르: **외우주 출처 재료로 장비 제작** 금기(공허 속성 자체는 금기 아님). 네레이아: 신성 수생 생물 포획/살해. 베르단: 신성 수목 벌목. 모르가: 신성 속성 사용. 아르벨: 밭 수확 방치 부패. 헤스란: 던전 포함 피 요구. 레티스: 정기 금전 봉헌.
- 아우터 갓 이름·인격은 있으나 성별 없음/불명. 미정인 축복·대사·품종을 임의 확정하지 않음.

## 판단 규칙
'금기'는 기술적 유효성 거부와 동일하지 않다. 게임 내 행동을 허용하며 **알려진 결과/신의 반응**을 보여 주는 것이 세계관 의도일 수 있다. 위험 행동을 UI에서 영구 비활성화하는 방식으로 확정하지 않는다. 세부 축복·수치가 미정이라면 해당 빈칸은 계속 미정으로 유지한다.
