# Somnium — M2 탐험·전투·생존 통합 개발 명세 v1.0

- 확정일: 2026-10-29
- 위치: M2의 단일 상위 개발·인수 계약. 시험 수치는 확정 밸런스가 아니다.
- 설계 기반: M2 기획 v0.2·v0.3 사용자 결정, 기존 `MASTER_ROADMAP`, `DECISIONS_AND_CONFLICTS`, 엔진 01~02 계약 및 M1 실제 기능.
- **범위 경계:** M1 PR #159는 2026-10-29 기준 Draft·미병합. M2 명세 확정은 M1 인수·병합 승인을 뜻하지 않는다.

## 1. 확정 사용자 선택

1. 전투는 **턴 기반**, 탐험 중 적과 조우하면 **별도의 전투 화면**으로 전환한다. 포켓몬스터 시리즈의 탐험/전투 화면 분리·상태 표시·행동 선택의 명료함만 참조하며 전투 공식을 복제하지 않는다.
2. 전투 참가자별 **상세 행동 순서**를 둔다. 별도 속도 능력치는 추가하지 않는다.
3. 비전투 **은신·우회·퇴각**을 실제로 유효한 해결 경로로 제공한다.
4. 사망은 영구 사망 없이 난이도별 차등 불이익을 적용하고, 적용되는 난이도에서는 **전리품 회수 지점**을 둔다.
5. 비전투로 위험을 극복해도 탐험·발견·해당 숙련 보상을 준다. 단, 처치 전리품과 동일하게 지급하지 않는다.
6. **전투 중 '위치 변경' 명령은 없다.** 전투 UI에 이동/위치 변경 버튼·전투 타일 이동·이동 AP를 구현하지 않는다. 기존 미궁 지도 위치는 전투 진입/종료 복귀에만 유지한다. 은신·우회는 탐험/조우 단계, 퇴각은 전투 행동으로 사용한다. 전투 내부 전술적 이동·거리 재배치 시스템은 M2 필수 범위 밖이다.

## 2. M2 완료 사용자 경험

생활·제작에서 확보한 장비·식량·회복 수단을 준비 → 기존 광역 지역/미궁에서 탐험 → 적·함정 발견, 은신·우회 또는 교전 선택 → 별도 전투 화면에서 참가자별 순서대로 공격/방어/기술/아이템/퇴각 → 승리 시 실제 전리품·숙련 획득, 패배 시 난이도별 부활·전리품 회수 → 휴식·회복 후 같은 세계와 저장 슬롯에서 지속 탐험.

M2는 전투 창의 버튼이나 모의 HP만 만드는 작업이 아니다. 플레이어/적 상태·시간·턴·RNG·숙련·아이템 소유권·세계 위치·세이브가 하나의 게임 흐름을 공유해야 한다.

## 3. 보존 계약

- 전역 레벨 없음: 7능력치와 54개 독립 숙련 유지. 별도 속도 스탯, 경험치 이중 원장 없음.
- **접수된 게임 내 실패 행동도 플레이어 1턴**; 형식적으로 유효하지 않은 명령은 0턴. 세계 시간은 정수 초이며 턴과 별도.
- 하나의 명령에서 HP·MP·아이템·RNG·숙련·세계·이벤트·시각이 부분 커밋되지 않는다.
- 영구 사망 없음. 인벤토리 무게 한도·수확 식품 자동 부패·일괄 자연 HP/MP/허기 감소율을 임의로 도입하지 않는다.
- 기존 16개 광역 지역 및 미궁 탐색 기반 활용; 별도의 전투용 지도 타일 세트나 전투 중 이동 시스템 구축 금지.
- 활성 몬스터/아이템 수치·AI·전리품·사망 불이익의 구체 값은 시험 설정으로 관리하고 확정 세계관으로 선언하지 않는다.
- 신앙·부활의 신학적 원리 및 신별 능력·금기 사후 효과는 M3 범위로 보류한다.
- 기존 IndexedDB/v3 저장 슬롯·원본·구형 저장을 무단으로 이전하거나 덮어쓰지 않는다.
- M1의 플레이어 소유 `itemWorld`, 요리·장비·숙련 및 생활 경제와 연결하며 전투 전용 복제 인벤토리를 만들지 않는다.

## 4. 탐험·조우 상태

- 미궁·지역의 기존 이동/시야/접근 가능 영역은 탐험 화면의 권위 상태다.
- 적은 최소 `무관심 → 의심 → 경계 → 교전 → 추적 → 이탈`의 필요한 상태 전이를 갖는다. 첫 구현은 단순 규칙형 AI로 제한한다.
- 탐색/관찰은 위험을 먼저 인지하게 하고, 은신은 감지·경계 판정, 우회는 기존 이동 가능한 경로를 활용한다. 결과에는 시간·경계·발견·위험 비용이 반영된다.
- 우회·은신 성공은 해당 적의 처치 전리품을 생성하지 않는다. 반복 왕복을 통한 무한 숙련 지급은 조우/발견 ID 기반으로 방지한다.
- 전투 진입 시 원래 지역·위치·조우 ID와 세계 시간을 보존한다. 전투 종료 후 동일 세계 컨텍스트로 되돌아가되 승리/퇴각/패배 결과만 반영한다.
- 임의의 위치를 전투 내부에서 선택하는 명령은 없다.

## 5. 전투 흐름과 상세 행동 순서

- 전투 화면: 상대/플레이어 HP·MP 및 상태, 현재 참가자, 다음 행동 순서, 행동 로그, 선택 가능한 **공격·방어·기술·아이템·퇴각**. 기술은 M2에 실제 정의된 비마법 기술만; 주문 완전체는 M3. 별도 '위치 변경'은 노출하지 않는다.
- 전투 개시 시 조우/기습·경계의 명시적 규칙으로 최초 행동 순서를 결정한다. 매 라운드 살아 있는 참가자 모두에게 정해진 행동 기회를 준다. 라운드 내 처리 순서는 결정적이어야 하며 시드 RNG 소비가 재현 가능해야 한다.
- 여러 적은 각자 차례에 판단·행동한다. 플레이어가 한 번 행동할 때 적 전체가 무조건 공격하도록 단순화하지 않는다.
- 별도 속도 스탯 추가 금지. 행동 지연·기절 등 명시적 상태 효과만 순서를 변경한다.
- 공격 시 공격 유형·관련 능력치·무기 숙련·장비·목표 방어·상태를 사용한다. 명중/피해/방어 값은 외부 시험 설정으로 두고 검증 가능하게 한다.
- 전투 명령의 성공·실패·방어·아이템 사용은 공통 디스패처로 처리. 적의 반응을 중복 플레이어 턴으로 계산하지 않는다.
- 퇴각은 항상 요청 가능한 실제 행동이지만 성공 보장은 없다. 성공하면 추적/탈출 결과를 기록하고 탐험으로 복귀하며 처치 보상은 없다. 실패하면 1턴과 반응 위험을 부담한다.
- 전투 시작/종료, 적 생존, 행동 순서, 상태 이상과 보상 지급 여부는 한 번만 확정되어야 한다.

## 6. 위험·회복·사망

- M2 최소 위험: 실제 적 조우, 발견 가능한 물리 함정 한 종류 이상, 환경 위험 한 종류 이상. 발견/해제/우회/강행은 각자의 실제 결과를 갖는다.
- 음식은 기본적으로 허기 회복, 회복품은 명시된 HP·상태 회복, 휴식·야영은 환경/위험 검사 후 HP·MP 회복. 전투와 이동의 보편적인 자연 감소율은 이 명세에서 만들지 않는다.
- 난이도별 정책을 데이터로 분리:
  - **편안함:** 안전 지점 부활, 영구/회수 대상 전리품 손실 없음.
  - **보통:** 안전 지점 부활, 명시된 일부 전리품이 사망 장소의 회수 보관함으로 이동.
  - **어려움:** 안전 지점 부활, 보통보다 넓은 대상 전리품·소모품이 회수 대상. 전리품과 보유품의 정확한 비율·범위는 시험 설정으로만 둔다.
- 캐릭터·숙련·정체성은 사망으로 삭제되지 않는다. 부활 장소와 상실 시간/상태량은 설정화하고 UI에 사전 표시한다.
- 회수 보관함은 위치·소유자·고유 ID·아이템 참조·회수 여부를 유지. 보관함 이동은 권위 인벤토리에서 원자적으로 차감하고, 이미 회수한 보관함은 중복 지급 불가. 접근 불능 장소의 안전 복구 정책을 반드시 제공한다.
- 영구 파괴·회수품 자동 소멸·몬스터의 장비 약탈은 M2의 필수 범위에서 제외한다.

## 7. 전리품·성장·자동화

- 전투 승리: 실제 소유 가능한 재료/도구/소비품과 관련 전투 숙련. 미승인 콘텐츠 자동 활성화 금지.
- 은신·우회·발견: 최초/유효 위험 극복 기준의 탐험/은신/관찰 숙련·기록·접근 보상. 적 처치 드롭과 구분.
- 플레이어 직접 행동과 자동 행동은 동일 명령, RNG, 시간, 피해, 드롭, 숙련 지급을 공유한다.
- 자동 설정: 공격/회피 우선 성향, HP·MP·허기 선택 임계치, 위험 감지 시 중단, 허용된 회복품 사용, 퇴각 시도. 임계치 이전 행동의 결과는 정상 커밋되고 **다음 행동 전** 중단한다.
- 보상과 회수는 조우/행동 요청 ID와 처리 완료 표식으로 중복 커밋을 차단한다. 한정된 ID 기록만으로 영구 exactly-once를 주장하지 않는다.

## 8. 저장·기술 계약

- 별도 전투 UI와 상태는 기존 `world.runtime` 및 v3 저장 확장 규칙을 먼저 계측한 후 추가한다. 미확인 필드 무단 삽입 금지.
- 저장 대상: 조우 ID, 전투 단계, 참가자·HP·상태, 행동 순서·라운드, RNG, 원래 탐험 위치, 완료된 보상, 전리품 회수 위치 및 지급 상태, 난이도. 전투 도중 저장·복원을 기본 지원한다.
- 상태 재개 후 적 턴 중복, 추가 피해, 같은 적의 보상 중복, 소모품 이중 차감은 금지한다.
- 저장 불가/손상·미지원 버전은 원본 저장과 현재 플레이 상태를 변경하지 않고 거절한다. 다중 탭 리비전 충돌 및 구형 슬롯의 원본 보호를 검증한다.
- 전투 완료 뒤 탐험 상태로 돌아올 때 원래 세계 위치와 결과를 단일 권위 상태에 반영한다.

**반례 게이트:** 유효하지 않은 actor/owner, 죽은 적 공격, 공격/회복 수치 NaN·음수·오버플로, 중복 행동·중복 승리/전리품·중복 회수, 적 턴 재실행, 전투 중 무단 탐험 이동, 명령 실패 턴 비용, 잘못된 저장 버전·RNG·참가자 순서, 다중 탭 충돌, 자동 중단 후 저장 및 재개.

**완료 기준:** E2E-01~09 전체 자동 통과 + Linux/Windows 엔진 검사 + 실제 Chromium 브라우저 상호작용 + 사용자 Windows Chrome/Edge 수동 검수(별도 인수). 일부 시나리오만 통과했다고 M2 완료 선언하지 않는다.

## 10. 구현 순서와 비범위

1. 탐험 조우 → 별도 전투 화면 → 행동 순서·공격/방어/HP·귀환.
2. 적 경계·은신·우회·퇴각 → 위험/함정 및 비전투 보상.
3. 전리품·전투 숙련 → 회복·난이도별 사망/부활·회수 보관함.
4. 자동 정책·전투 중 저장/복원 → 9개 인수 시나리오·CI/수동 QA.

범위 밖: 전투 위치 변경/전투 타일 이동, 동료 파티·소환수 복잡 행동, 부위별 상세 부상, 수십 상태 이상, 대규모 몬스터/보스 AI, 장비 내구도 전면 개편, 마법 주문 전체, 신앙 기반 부활 서사·효과, 미승인 종족/몬스터 대량 활성화.
