# 03-B 광역 여행 구현 및 검증 — 1차

2026-10-22 · PR #24 · 베이스: `feat/03a-world-contract-finalization`

## 구현된 기능
- `world/travel.ts`의 경로 탐색: 빠른 길(세계 시간), 안전한 길(이미 알려진 위험), 적은 행동 턴. 동점일 경우 edge ID를 사용해 결정적 결과. 일방통행, 통행 요구조건, 미발견·만료 사이트를 배제한다.
- 순수 상태 전이: 여행 계획 → 시작(일시정지) → 재개 → **한 번에 1턴** 이동 → 구간 도착 → 목적지 도착, 중단/일시정지/재개.
- 세계 시간은 간선의 `worldUnits`를 정수 비례 분할하여 모든 턴 합이 원래 간선 비용과 정확하게 일치한다. UI 경로 확인·정지·재개는 0턴.
- 중간 구간에서 `취소`는 플레이어의 강제 순간이동 위험이 있어 거부한다. 구간 경계에 도착한 다음 취소 가능. 향후 경로 중간 조우·우회 지점을 구현하면 이동 도중 취소를 재설계.
- 메인 지도 클릭 → 경로 미리보기 및 승인 → 한 턴씩 진행·일시정지·재개·취소. 기존 바로 순간이동 UI는 교체.
- 현재 v2 `world.runtime.travel03B`에 계획/진행상태를 저장하므로 기존 v2 저장 봉투로 직렬화될 수 있다. 단, 03-B 전용 내용에 대한 엄격한 저장 통합 검증과 과거 세이브 전환은 추가 작업이 필요하다.
- 16개 지역 지도는 기존 **03-A 시험용 1열 연결 그래프** 기반으로 동작. 이것을 실제 세계 지리적 최종 연결이라고 이해하면 안 된다.

## 알려진 제약
- 현재 `world.runtime.travel03B`의 별도 버전과 깊은 불러오기 검증은 제한적. 실제 데이터 포맷 변경 때에는 명시적 마이그레이션이 필요하다.
- 여행 중 자동 반복 틱, 플레이어 위험/허기 중단, 조우 사건, 실제 통행 조건의 동적 변화는 아직 메인 UI에 완전히 연결되지 않았다. 틱 버튼 1회가 하나의 행동을 처리하며 안전하게 수동으로 확인 가능.
- 03-A의 자기 자신을 가리키는 출입구는 아직 테스트용이다. 도착지 로컬 입구로 플레이어 타일을 자동 배치하는 연결은 03-C에서 완성.
- 유저가 정한 **무게 없음**, 버린 아이템 영구 소멸은 유지.
