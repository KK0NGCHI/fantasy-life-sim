# 대규모 로드맵 I단계 — 공통 제작 실행기 1차 통합

2026-10-27. [통합 로드맵 v2](./resource-crafting-roadmap-v2-consolidated.md) 단계 I의 **진행 중 작업**이다. 이 PR을 I단계 완료로 오해하지 않는다.

## 구현
- `craftPreview1`: 05-J 재료 할당기를 바탕으로 정확 ID 및 호환 family/form/grade를 함께 고려하는 제작 가능 판정.
- `craftBatch1`: 같은 재료 소비·조성 기록·스택 처리기로 최대 20회 반복. 모두 성공해야 재고 적용; 중간 실패는 **일괄 무효**. 직접 반복 실행과 결과 일치.
- `craft.batch` 실제 게임 디스패처: 거점 마을 시설 접근, 작업별 시간 × 횟수 및 횟수별 논리 턴, 무결성 검증, 저장 v3 동일성.
- 제작 UI: 범용 호환 재료 수요 표시, 부족/불일치 사유, 1/2/5/10/20회 선택.
- `mineral.refine` 기존 단일 제작과 05-H/I 17개 레시피는 보존.

## 남은 I단계 핵심
1. 원하는 재료 스택/대체재의 **직접 선택** 및 복수 슬롯 동시 예약 판정.
2. 긴 반복/자동 제작 **중도 중단 정책** (현재 원자적 일괄 제작, 자동 루프/부분 성과 보존은 미구현).
3. 공통 작업대·도구 요건/레시피 분류 및 사용성 정리, 적절한 제작 패널에서 재료 선택과 부족 설명.
4. 신성/이질 **출처 메타데이터와 금기 판정**, 모든 실행 가능한 제작법에 재료 구성 보존 일관성 적용.
5. UI 수동 플레이, 장기 시나리오, save v3 훼손 거절·역호환 회귀 검사.

## 명시적 미구현
- 진행 중 작업의 부분 완료/취소와 자동 예약 제작, 자재 예약, 작업대 아이템 소유/배치, 무역/경제/주거 연동.
- 이 PR에서 새로운 원천·아이템·제작법을 추가하지 않는다.
