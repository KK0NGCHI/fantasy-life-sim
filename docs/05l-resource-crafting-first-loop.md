# 05-L 첫 실제 생활 제작 루프

2026-10-27 / 실제 신규 제작 연결. 승인된 v0.5 설계의 제한적 활성화.

- 들풀 item05a:grass 3개 → 풀섬유 밧줄 item05l:grass-rope 1개. 거점 마을, 300초.
- 호환 목재 판재 2개 + 밧줄 1개 → 목재 바구니 item05l:wood-basket 1개. 거점 마을, 600초.
- 현재 검증된 호환 판재는 item05h:oak-planks 단일 종류뿐이다. 다른 수종의 판재를 게임에 등록하고 기원·물성 검증이 끝나야 해당 재료도 호환된다.
- 메인 제작 탭과 기존 mineral.refine 명령을 사용한다. 기존 05-H/I 시간·재료·결과·save v3 정의는 변경하지 않는다.
- 바구니는 현재 **제작 가능한 아이템**일 뿐 실제 저장 용기나 가구 배치 기능은 아니다.
- 매칭의 속성 메타데이터는 정적 신뢰 정의만 사용한다. 재료 부족, 타인 소유 재고, 잘못된 재료는 소비 없이 거절한다.
