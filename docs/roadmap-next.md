## 05-A 첫 Vertical Slice 권장안
처음부터 모든 16지역의 모든 재료를 제작하지 않는다. 다음 한 가지 순환을 먼저 통과시킨다.

1. 숲의 유효 자원 노드에서 벌목 실행. 중앙 디스패처로 시간·턴 계산.
2. 실제 성공과 생산량 검증 후 월드 노드 상태 감소 + 원자적 인벤토리 획득 + 벌목 숙련 XP 지급.
3. 같은 노드를 반복 채취해 소진이 기록되고, 정의된 게임 시간·조건에서만 회복.
4. 지도 이동 후 귀환·F5 저장·브라우저 새로고침·F9 불러오기 시 노드 상태·아이템·XP·시간이 동일.
5. 최소한의 UI로 현재 가용 수량, 예상 행동 비용, 결과·소진·회복 정보 표시. 절제된 기존 UI 설계 시스템을 따름.
6. 반례 테스트: 잘못된 지역·미존재 노드·소진 노드·중복 actionId·동시 저장·과거 세이브/지도 델타 누락.

이 슬라이스가 통과하면 채집·채광·낚시로 동일 계약을 확대한다. 실제 채굴·낚시 난도와 시간은 조사·시뮬레이션을 통해 조정하며 임시값을 최종 밸런스로 고정하지 않는다.

## 공통 품질 게이트
- GitHub에서 작업별 별도 **Draft PR**; base는 현재 스택 최상위 브랜치. `main` 병합은 사용자가 명시적으로 승인할 때만.
