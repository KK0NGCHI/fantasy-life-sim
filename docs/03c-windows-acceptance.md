# Somnium 03-C — 로컬 탐험 통합 및 Windows 검수

2026-10-23 · 브랜치 `feat/03c-completion-windows` · PR #34 (Draft)

## 구현
- 광역/로컬 UI 위치와 별개로 레지스트리 기반 상하좌우 이동·벽 실패·초 단위 비용 처리.
- 지도 타일에서 시야 계산, 현재 보이는 타일과 기억된 타일을 구분하는 뷰. 브라우저 세션에서 방문 기억을 유지. **기억의 v3 저장은 아직 미완료**(03-E).
- 자동 탐색은 현재 알려진 셀만 이용해 BFS 경로를 만들며 일반 이동 디스패처를 반복 호출한다. 기존 사용자 HP/MP/허기 중단 임계값 유지. 숨은 위험에 대한 미래 정보는 이용하지 않는다.
- 시험용 지하미궁 0층 ↔ -1층의 명시적 상호 계단 링크. 계단 타일에 도착하면 '계단 이용' 조작이 나타난다. 전환은 중앙 dispatcher를 거치며 1턴/6초.
- 로컬 이동/시야·포털과 자동 경로 분리, 단위 테스트 및 메인 통합 테스트 추가.
- 기존 v2/v3 DB 이름 및 저장 포맷은 변경하지 않는다. 기존 스냅샷의 `localFloor` 부재는 기본 0층으로 처리한다.

## 한계와 03-E 이관
- 5×5 맵은 게임 콘텐츠가 아닌 검증 fixture. 실제 시드 생성 필드/던전은 03-D 작업.
- 현재 시야의 `localRemembered`는 UI 메모리에만 있고 새로고침·로드 후에는 재계산한다. 영구 탐험 기록·세계 상태의 단일 정본은 03-E 스키마 마이그레이션에서 처리한다.
- 지형별 미발견 위험·몬스터·상호작용 콘텐츠는 후속 시스템. 이번 자동 탐험은 이미 기억한 경로의 안전 이동만 수행한다.
- 새로 추가한 `localFloor`의 정식 상태 검증/세이브 이전을 03-E에서 강화해야 한다. 데이터가 없으면 0층으로 간주한다.
- Windows 실제 브라우저 시각·조작 검수 결과는 사용자가 실행하기 전까지 미확인.

## Windows PowerShell 실행
```powershell
git fetch origin
git switch feat/03c-completion-windows
git pull --ff-only
npm ci
npm run check
py -m http.server 8000
```
`py`가 없다면 `python -m http.server 8000`. 브라우저에서 http://localhost:8000/ 열기. 캐시된 자산은 `Ctrl + Shift + R`로 갱신. 서버 중단은 PowerShell에서 `Ctrl + C`.

## 직접 확인할 사항
1. 첫 게임 시작 시 08:00:00; 던전 진입 후 방향키로 한 칸 이동 → 게임 시계 6초, 턴 1 증가. 벽 충돌은 위치 유지·1턴/6초.
2. 던전의 0층 (2,2)에서 오른쪽 1칸·아래 1칸 이동해 (3,3) 계단에 도착. `계단 이용` → -1층 (1,1) 도착. 같은 버튼으로 0층 (3,3) 복귀.
3. 자동 탐색을 시작하고 중단 버튼·HP/MP/허기 임계값 확인. 일반 디스패처에서만 시간 처리되는지 확인.
4. 저장 F5 → 새로고침 → 불러오기 F9. 층 위치·시간·아이템 비교. **시야 기억은 현재 저장 대상이 아님**.
5. 기존 v2 슬롯이 보존되고, 명시적 승인 없이 v3로 변경되지 않는지 확인.
6. Chrome과 Edge에서 각각 확인. 개발자 도구 콘솔에 엔진 오류 없는지 확인. CPU 점유·자동 반복 중단도 살펴본다.

개발 완료와 Windows 브라우저 검수 완료는 별도 판정한다.
