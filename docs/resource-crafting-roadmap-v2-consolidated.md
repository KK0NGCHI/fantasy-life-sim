# Somnium 자원·제작 통합 개발 로드맵 v2 (2026-10-27)

> **현재 우선 개발 계획.** 이전 05-M~05-Q의 자원별 작은 PR 진행표를 대체하는 **5개 대규모 개발 단계**. 사용자의 요청에 따라 제작법 몇 개 또는 PR 한 개를 독립 개발 단계로 보고하지 않는다. 세부 PR은 검증·릴리스 수단일 뿐, 단계 완료는 분야 전체 기준으로 판단한다.

## 목표 및 경계
- 원천 → 발견/획득 → 부위별 산출물 → 가공 → 제작/연구/도감 → 실제 아이템 상세 → 저장/반복 행동의 일관된 공통 시스템 완성.
- 주거, 경제, 농업, NPC/생활 시스템의 본격 연동은 **기반 완성 이후** 진행한다. 기능 없는 가구·주머니 등에 배치/수납/능력치 효과를 암시하지 않는다.
- 사용자 승인 사항: 완성품에는 **직전 제작에서 실제 소비된 재료의 종류/수량만** 표시. 채집지, 일시, 전단계 모든 가공 이력 추적은 불필요. 신성/이질 출처 등 금기 판정에 필요한 메타데이터는 보존.
- 348개 후보 원천, 384개 지역 관계, 539개 산출물 부위 후보, 56개 기획 레시피를 전반적으로 **감사하고 정규화**하되 자동 활성화하지 않는다. 콘텐츠 통과 상태 `candidate/approved/discoverable/obtainable/processed/craft-usable/ui-tested/save-tested`를 분리한다.

## 개발 및 보고 운영 원칙
1. 사용자가 승인한 **하나의 큰 단계**를 한 번의 개발 목표로 잡는다. 단계 목표를 기능 2~6개 단위의 새 ‘마일스톤’으로 계속 잘게 쪼개지 않는다.
2. 기술적 안전 때문에 PR은 여러 개로 나눌 수 있다. 그러나 일일/대화 진행 보고는 **큰 단계 진척·남은 작업·결함/위험·예상 완료 조건** 중심으로 한다. 작은 PR 병합 자체를 단계 완료로 표현하지 않는다.
3. 단계 전/후 비교에는 (a) 승인 원천 수, (b) 실제 발견/획득 가능, (c) 가공 가능, (d) 제작/연구·도감 연계, (e) UI·저장 검증 통과 수를 표시한다. 목표 숫자는 실측/승인 후 확정하고 임의로 100% 표시하지 않는다.
4. 공통 시스템이 안정적으로 재사용 가능하도록, 데이터 중심 콘텐츠 등록, 정식 ID/동의어/종/광상 구분, 재료군 조건, 부위·공정 분리를 공통적으로 사용한다.
5. 완료는 구체적 테스트와 플레이 경험으로 판단. 기능 하나 추가 후 전체 완료라 부르지 않는다.

## 제약
- 기존 05-H/I 17개 레시피와 save v3의 구형 데이터를 파괴하지 않는다.
- 인벤토리 식품 부패 없음; 성장 중 작물 과숙 가능. 심해 접근을 낚시 레벨만으로 허가하지 않는다.
- 보호받는 신성 수목 **벌목**, 신성 수생 생물 **포획·살해**, 이질적 기원 **장비 제작**만 각 관련 금기 행동으로 판단한다.
- 식용·약용·독성, 실재 종명과 서식, 판타지 세계관은 검토 전 확정 사실로 다루지 않는다.
