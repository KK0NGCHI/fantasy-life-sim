# 01-B — 공통 행동 처리 및 턴 계약

## 적용 범위
- 기존 UI에는 연결하지 않은 독립 TypeScript 모듈.
- `ActionDispatcher`가 동기적 명령의 재진입을 막으며 `dispatchAction`으로 행동을 실행.
- 행동 처리기는 등록된 타입에 따라 결과 상태와 의미적 이벤트를 반환.
- 성공과 **게임 내 실패 모두 정확히 1턴 소비**. 미등록 명령, 잘못된 actor, 형식 오류는 `INVALID_COMMAND`로 0턴.
- 행동 처리 중 예외나 결과 계약 위반은 `EXECUTION_ERROR`로 0턴. 입력 상태는 복사해 전달하여 부분 변경을 막음.
- 아직 세계 시간 단위·시계 진행, 난수, 자동 행동, 아이템 보상 공식 등은 구현하지 않음.

## 기존 상태와 구별할 점
`src/v3.js`와 `src/data.js`의 상태/아이템은 UI 목업이며 실제 엔진 데이터가 아님.
테스트용 `test:move`, `test:rest`, `test:gather`는 테스트 안의 핸들러이고 실제 콘텐츠나 행동 규칙이 아님.

## 검증
```bash
npm install
npm run check
```
테스트에서는 이동 성공, 벽에 막힌 이동, 채집 실패, 3회 연속 휴식, 유효하지 않은 명령, 핸들러 예외, 중복/재진입을 검증.
기존 UI 파일은 변경하지 않음.

## 01-C·02단계에 미룸
- 세계 시간 단위 및 캘린더·시계 갱신
- 시드 기반 RNG, 자동 진행 및 중단 조건
- 스키마 수준의 깊은 런타임 데이터 검증 및 JSON 직렬화
- IndexedDB 저장과 외부 파일
- 중복 네트워크 요청/비동기 행동 idempotency (현재 행동은 동기 실행만 지원)
