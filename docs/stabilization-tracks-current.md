## 이 문서를 갱신하는 기준

1. PR 번호/병합 커밋/검사 결과/테스트 이름을 근거로 기록하고 **구현과 QA를 구분**한다.
2. 새 트랙 작업 시 '문제 → 수정/검사 → 결과 → 미검증 영역'을 항목별로 갱신한다.
3. 제안된 카탈로그 규모가 곧 플레이 가능한 콘텐츠의 범위를 뜻하지 않는다.
4. 기존 세이브 **데이터** 폐기는 허용되지만 사용자 세계관 결정이나 원본 기획 파일까지 삭제하라는 뜻은 아니다.
5. 당장 우선 순위: (a) 장시간 식물·균류 재고 회귀, (b) 자원 공급→가공→도구 제작 연결 현황 측정, (c) 밸런스 수치 출처와 설정 분리, (d) 문서 대조.
6. 05-I까지의 구현 경로는 05-A부터 이어지는 이전 단계 로드맵을 일부 추월했다. 과거 로드맵의 미구현 표시를 그대로 현재 판정으로 사용하지 않는다.
