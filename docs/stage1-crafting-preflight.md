# 1단계 제작 사전 안내·실행 판정 일치

제작 가능 미리보기는 실제 할당한 재료에 대해 `checkCraftingTabooStage1`을 실행한다. 제작 금기 원인은 임의 클라이언트 메타데이터가 아닌 서버 코드에 등록된 재료 정의에서 판정한다. 이질 기원 장비 제작을 허용하지 않는 것은 **장비 제작 행동**에 한정한다.

제작 UI는 재료 부족, 잘못된 스택 선택, 이질 기원 금기, 시간 제한으로 인한 작업 불가능, 마을 설비 부재를 구별해 안내한다. 후보를 볼 수 있다는 이유만으로 제작을 허용하거나, 실제 처리기가 거절하는 행동에 대해 '가능'이라고 표시하지 않는 것이 목표다.

이번 PR은 승인된 특수 원천을 새로 활성화하지 않는다. 실제 sourceId 연결은 원천 정의 승인과 획득 경로 구현이 먼저 필요하다. Stage I 최종 완료는 생존 변화 규칙의 정식 통합, 도구 요구조건, UI 수동 검수도 통과해야 한다.
