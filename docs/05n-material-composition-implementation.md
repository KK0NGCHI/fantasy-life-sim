# 05-N 제작 재료 구성 표시: 제한적 첫 구현

2026-10-27. 전체 출처 추적을 만들지 않고 **직전 제작에 실제로 투입된 아이템 정의·수량**만 완성품에 저장한다.

- 데이터: 기존 `ItemInstance.condition.materials05n`에 간결한 JSON 문자열을 기록한다. 저장 v3 버전/스키마의 필수 필드를 바꾸지 않는다. 새 기록은 05-L/05-M 제작법에 우선 적용한다.
- 범용 제작에 자작나무 판재를 쓰면 자작나무 판재라는 실제 정의 ID와 수량을, 참나무 판재를 쓰면 참나무 판재와 수량을 기록한다.
- **서로 다른 조성은 다른 재고 스택**, 같은 조성은 같은 스택으로 합칠 수 있다. 기존 고정 ID의 05-H/I 제작 처리기는 유지하고, 과거 제작품에 임의로 재료를 채워 넣지 않는다.
- 인벤토리 상세 화면은 `condition`을 읽어 실제 사용한 재료 이름과 수량을 표시한다. 기록 없는 아이템에는 그 사실을 명시한다.
- **전체 이력은 기록하지 않는다.** 수피판으로 만든 바구니의 상세에는 직접 사용한 수피판과 바구니만 보이고, 그 수피판의 원천 지역·제조 시각까지 따라가지 않는다.
- 저장 안정성: `condition`은 기존 아이템 검증기에 이미 지원된 문자열 필드다. 잘못된 기록은 상세 UI에서 해석하지 않는다.
- 선결된 legacy 스택과 신규 서명을 가진 제작품의 스택을 섞지 않는다. 기존 저장과 레거시 05-H/I 출력 식별자 불변.
- 향후 확대 전 확인할 것: 가공 작업을 자동 반복/대량 일괄 제작할 때 표시 단위(개별 완제품 vs 제작 배치), 구형 아이템 마이그레이션 여부, 중간재·장비를 포함한 모든 제작 경로의 표시 정책, UI 수동 검수.
