# 05-I · 가공품에서 작업 도구 제작으로 연결

기존 05-H 작업대 UI와 itemWorld 원장을 재사용하여, 정련된 주괴 및 가공 석재에서 곡괭이/벌목 도끼를 만들 수 있도록 연결한다.

- 구리·철·청동 각각 곡괭이와 도끼 2종, 총 **6개 제작법**을 추가한다.
- 각 제작법은 해당 금속 주괴 2개 + 다듬은 석재 1개를 소비하고 도구 1개를 생성한다.
- 결과물은 기존 `tool05a:pickaxe:copper`, `tool05a:axe:iron` 등의 정식 도구 아이템 ID를 사용한다. 청동 도구 2종만 새로 등록하며 등급은 임시로 구리 도구와 같은 2등급이다.
- 거점 마을의 공용 작업대에서만 제작 가능하며, 가공 UI의 실제 인벤토리 수량에 따라 버튼이 활성화된다.
- 재료 입력 전체를 확인한 뒤 원자적으로 차감·지급한다. 부족한 재료 또는 다른 캐릭터 소유 재료로 제작할 수 없다.
- 저장 v3 스키마, 광맥 저장 구조 및 기존 단일 채광은 변경하지 않는다.
- 다듬은 석재·점토벽돌을 건축물에 소비시키는 동작은 현재 건축 엔진과의 계약이 없어 구현하지 않는다. 자원을 소비할 구조물이 확인되기 전까지 ‘건축 연결 완료’로 간주하지 않는다.

소요 시간·필요 주괴 수는 초기 밸런스이며 추후 도구 제작 기술·내구도 시스템과 연결할 수 있다.
