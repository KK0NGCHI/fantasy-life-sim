# Somnium 05-E · 창작·코스믹 광물 후보 부록 v0.1

> **기획용 제안 / 세계관 정설 아님 / 게임 미구현.** 아래 명칭·기원·효과는 새로 제안한 임시 후보이며 기존 기술 명세의 확정 설정이라고 주장하지 않는다. 플레이어가 과학적으로 이해할 수 있는 현실 광물 94항목과는 분리한다. 실제 아이템 ID, 등장 지역, 희귀도, 채굴 난이도, 수급량, 마법 체계는 확정하지 않는다. 최종 명칭도 검토 대상이다.

## 분류 철학

- **변성·마력 영향 광물**: 현실 광물/암석의 기본 정체성이 유지되면서 특이 환경에 의해 새로운 '속성/상태'가 붙은 경우. 일반 광물종을 불필요하게 복제하지 않는다.
- **창작 광물종**: 현실 광물종과 다른 물질적 정체성이나 제작 역할이 있는 세계 고유 후보. 출처와 마법 시스템이 확정되어야 도입한다.
- **코스믹 광물·이질 광체**: 천체·차원·인식·시간 등 초상적 조건을 가진 물질 후보. 지역만 보고 '우주' 성질을 자동 부여하지 않는다.
- **특수 광상**: 채굴 대상 물질이 아니라 생성 환경 및 여러 원료의 조성. '심연 광맥'과 '심연 광석'을 같은 ID로 취급하지 않는다.

## 시스템 설계 제안

```text
geological_material:
  id: proposed-material-id
  baseMaterialId: optional-real-mineral-id
  ontology: mineral_species | rock | ore_material | altered_material | exotic_matter
  status: proposal
  traits: [optional-validated-trait]
  formationTags: [proposed-environment]
  provenance: provenance-record-not-region-derived

deposit:
  id: proposed-deposit-id
  environmentId: proposed-environment
  hostRockIds: [...]
  materialAssemblage: [{materialId, proportion}]
  formationEventId: optional
  finiteReserve: ...
  discoveryRequirements: [...]
  hazardPolicy: ...
```

**원칙:** 같은 지질 환경에 있더라도 모든 광물에 초자연적 속성을 부여하지 않는다. 기원·채굴 이력·특수 환경 노출 여부는 개별 산출물의 출처 기록으로 검증한다. 기존 광맥 저장 구조에는 제안 필드를 즉시 추가하지 않는다.

## 단계적 채택 제안

1. 현실 광물의 **변성 특성 2~3개**를 먼저 선택해 기존 원석/품질 시스템에 실험적으로 붙인다.
2. 제작·생활 기능에 쓰일 **창작 광물 2~3개**를 검토한다.
3. 코스믹 광물은 관련 세계관·발견 사건·제작 기능이 승인된 후 소량만 도입한다.
4. 코스믹 광상은 별도 사건/환경 시스템이 준비된 후에만 생성한다.

## 기획상 보류

용어 '코스믹'이 천체 기원인지, 우주적 공포/차원이상인지, 특정 신성/마력 개념인지 확정되지 않았다. 따라서 위 C/D는 **다양한 해석을 열어 둔 디자인 후보**이며, 기존 종교·종족·마법 체계에 새로운 정설을 추가하지 않는다.
