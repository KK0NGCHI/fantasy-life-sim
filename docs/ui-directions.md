# UI 방향 검토 — 2026-10-22

## 확정/미정 분리
확정: 상단 상태/좌측 지역과 행동/중앙 콘텐츠/우측 실시간 로그/하단 메뉴, 컬러 타일 던전, 자동 탐색은 던전에만 노출, 콘텐츠 데이터 외부화, 카드형 대시보드 금지. 미정: 성장·경제·품질 공식, 실제 턴당 시간, 색채/타이포 최종 선택. 시제품 값은 실제 시스템 기획에 영향을 주지 않는다.

## 레퍼런스와 평가
- DCSS WebTiles: 스탯·지도·메시지를 함께 봄. 로그 채널/키보드 내비게이션 참고. 던전 우선 UX와 ASCII는 가져오지 않음. https://crawl.develz.org/wordpress/
- Cogmind: 중요 사건의 색상 차별화와 정보 밀도 참고. 네온 전용 팔레트와 과밀성은 지양. https://www.gridsagegames.com/blog/2024/02/full-ui-upscaling-part-5-completion-and-demos/
- Caves of Qud: 색상과 타일의 정보표현, 용어 상세설명 참고. SF풍 전체 UI 복제 금지. https://www.cavesofqud.com/
- Elin: 상세 아이템/제작 UI 비교 대상으로 포함. 중첩 패널·과도한 클릭은 지양. https://ylvapedia.wiki/wiki/Elin:Items
- WCAG 2.2: 키보드 포커스, 본문 최소 대비 4.5:1을 검증 목표로 사용. https://www.w3.org/TR/WCAG22/

## 3개의 서로 다른 후보
A 생활 작업대: 편집 문서 같은 밝고 따뜻한 작업 공간, 정렬된 표/목록, 차분한 액센트. 생산/제작 장시간 플레이 최적이나 위험 강조가 약할 수 있음.
B 고전 CRPG 도구: 다색 기능 패널과 일정한 상태 공간, 높은 정보 밀도. 단 UI 요소 구획이 지나치게 많을 수 있음.
C 타이포그래피 터미널: 위험 로그/키보드 중심, 작은 보조 정보. 밀도는 강하나 생활 게임에 전투 집중 인상을 줄 위험.

## 채택한 시제품
B의 어두운 작업 공간과 A의 표·타이포 구조를 혼합한 *검토용* 화면. 색 역할: 배경 잉크 #171d21, 영역 바탕 #20292b, 텍스트 아이보리 #e9e3d7, 생활/획득 녹색 #a0c48f, 주의/제목 황동 #e2bb70, MP/탐색 청록 #83c8d2, 피해 적색 #e59b8d, 신앙 자주 #b9a2db. 전면 테두리/둥근 카드/그림자는 사용하지 않는다. 수치 tabular, 키보드 focus-visible 2px. 단일 색상 또는 색만으로 상태를 표시하지 않음.

최종 디자인 확정 전 확인 항목: 1366×768·1920×1080·좁은 창에서의 브라우저 실측, 한국어 줄바꿈, 다양한 로그 길이, 대비 계산, 90~140% 글자 크기, 키보드 이동 및 모바일 조작. 지금 문서는 렌더링 검증 결과를 주장하지 않는다.
