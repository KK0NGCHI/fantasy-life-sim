# 05-N 재료 역할 기반 추가 제작법

2026-10-27. 새로운 자원 원천이나 설비를 추가하지 않고, 기존 목재 판재·식물성 천·실·갈대 섬유·버드나무 엮음재·자작나무 수피판·정제 송진의 활용을 넓힌다.

| 완성품 | 구조재 | 기능재 | 결속재 |
|---|---|---|---|
| 목재 틀 직물 패널 | 호환 판재 ×2 | 식물성 천 ×2 | 식물성 실 ×1 |
| 갈대 가림막 | 호환 판재 ×2 | 갈대 섬유 ×3 | 버드나무 엮음재 ×2 |
| 목재 필기판 | 호환 판재 ×2 | 자작나무 수피판 ×1 | 정제 송진 ×1 |
| 송진 결합 수피함 | 호환 판재 ×2 | 자작나무 수피판 ×2 | 정제 송진 ×1 |

- 각 슬롯에는 `structural`, `functional`, `binding` 역할을 문서화한다. 현재는 레시피의 의미 기록이며 스탯 보정이나 역할별 내구성 계산을 구현하지 않는다.
- 판재는 공통 `processed_wood/plank/grade 1+` 슬롯을 사용한다. 참나무·자작나무·버드나무 각각 허용하고 실제 소비 재료의 정의 ID·수량을 완성품에 기록한다.
- 재료 부족/불일치 시 원자적으로 거절하며 동일/상이 재료 조성 중첩 정책은 05-N 기존 계약을 따른다.
- 마을 작업대에서 제작 가능한 **인벤토리 물품**이다. 설치, 기능성 보관함, 장비 효과 등은 아직 없다.
