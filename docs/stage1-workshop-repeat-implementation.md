# 대규모 로드맵 I단계 — 공통 제작 설비 및 반복 중단 정책

이 작업은 통합 1단계의 일부이며 **1단계 전체 완료를 의미하지 않는다.**

- 공용 작업대(`workbench`)와 용광로(`furnace`)를 정식 설비 ID로 판정한다. 현재 두 시설 모두 거점 마을에 고정돼 있고, 던전에서 사용할 수 없다. 개별 설비 설치/소유 규칙은 후속.
- 기존 단일 제작 `mineral.refine`과 원자적 `craft.batch` 모두 같은 시설 접근 판정을 사용한다.
- 신규 `craft.until`은 명시적으로 선택한 최대 20회 범위에서 재료가 바닥나면 중단한다. **완료한 수량만 지급하고 그 횟수만큼 턴/게임 시간을 사용한다.** 실패한 시도에 추가 시간/자원을 부과하지 않는다.
- 기존 `craft.batch`는 중간 부족 시 **전부 취소** 정책을 유지한다. 둘은 서로 다른, UI에서 구분되는 정책이다.
- 모두 수동 명령 시 동기적으로 처리하며 오프라인 백그라운드 자동생산이나 장기간 예약은 없다.
- 시험/자동검사: 설비 접근 차단, 원자적·부분 완료 비교, 완료한 횟수 시간 정합성, 저장 v3 왕복, 영회 완료 실패 불변.
- 단계 I 미완료: 구체적인 아이템 스택 선택과 수량 예약, 출처별 특수 재료/금기 판정, 설비 조건을 확대할 때의 실제 월드 소유권 연결, 긴 자동작업 안전 중단, UI 수동 QA.
