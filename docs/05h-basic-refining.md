# 05-H 최소 정련·제련 연결

광맥 구조 확장을 종료하고 `채굴 → 자원 소비 → 가공품 획득`에 필요한 첫 가공 규칙을 구현한다.

- 구리광석 2 → 구리 주괴 1, 철광석 2 → 철 주괴 1, 주석광석 2 → 주석 주괴 1.
- 돌 2 → 다듬은 석재 1, 점토 2 → 성형 점토벽돌 1.
- `mineral.refine` 명령은 실제 플레이어 인벤토리에 소유한 입력 재료만 사용한다. 실패 시 상태와 게임 시간을 변경하지 않는다.
- 기존 `itemWorld`와 save-v3을 그대로 사용하여 별도의 가공 자원 재고·저장 스키마를 만들지 않는다.
- 공정 시간은 금속 600초, 비금속 300초의 **임시 밸런스**다.
- 아직 용광로/작업대 보유 여부를 확인하는 작업 시설 규칙, 연료, 온도, 금속 제작법, UI 버튼은 적용하지 않는다. `station`은 후속 제작 시설 검증을 위한 메타데이터일 뿐 현재 시설 필요 조건이 아니다.
- 실제 플레이어에게 정식 공개하기 전에 시설·연료 요구, 결과 도감 표시, 저장 복원, 반복 가공 방지, 도구 제작 연결을 검증한다.

이번 단계는 광물 94종 전체를 억지로 제련하지 않는다. 실제 가공 공정을 가진 광물별 레시피는 이후 생활 제작 시스템과 연결한다.
