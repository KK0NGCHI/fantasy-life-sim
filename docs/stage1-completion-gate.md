# Somnium — 통합 1단계 완료 게이트 / 미충족 항목 (2026-10-28)

검증 기준은 [5대 통합 로드맵](./resource-crafting-roadmap-v2-consolidated.md)의 I단계이다. **PR 병합만으로 I단계 완료 선언 금지**.

## 자동 검증 가능한 구현
- 기존 활성 제작법의 설비·입력·제작 시간·출력 수량 정의가 정상임
- 재료 종류/소지 스택 선택, 타인 스택 거절, 범용 재료 할당/중복 소비 방지
- 단일 제작 20회와 원자적 20회 제작 동등성, 05-N 재료 구성 기록
- 실패의 원자성, 재료 고갈시 부분 완료, 시간 상한, 실제 완료 횟수 턴 계산
- save v3 왕복과 레거시 제작물 공존은 기존 05-N 및 Stage I 테스트로 검사
- 이질 기원 장비 제작 금기: 정적 신뢰 정의 기반 사전 거절
- 제작 시작 전 HP/MP/허기 제한과 UI 경고

## 단계 완료를 가로막는 미충족 조건
1. **행동 시간에 따른 생존 변화 규칙 부재.** 현행 게임 디스패처는 제작 턴/초를 마지막에 일괄 기록하며 HP/MP/허기는 변화하지 않음. 제작 중 '임계치 도달 시 중지'를 실제로 구현했다고 간주할 수 없다. 사용자 승인 없이 허기 감소 속도, HP/MP 자연 감소, 피로 수치 등을 상수로 발명하지 않는다.
2. **특수 자원 실제 연결 부재.** 칼두르 금기의 코드 기반은 있지만 아직 이질적 소재의 정식 sourceId/itemDefinition 관계와 실제 획득 경로가 없음. 신성 수목 벌목·신성 수생 포획 금기는 해당 행동 영역 개발에서 개별 연계 필요. 일반 신성·몽환·공허 재료에 잘못 확대하지 않는다.
3. **UI 수동 플레이 검수 미완료.** CI Chromium 스모크는 전체 제조·중단·저장 화면의 사람이 직접 수행한 QA를 대체하지 못함.
4. **도구/설비 확대 미완료.** 현재 작업대·용광로는 거점 마을 고정 서비스. 레시피별 도구 또는 배치 설비 요구사항이 공식 정의되지 않아 임의 생성하지 않는다.

## 구현 선택지
- 생존 시간 경과에 따른 상태 변화가 확정되는 즉시, 제작 완료 경계에서 해당 전이를 적용하고 다음 제작 가능 여부를 검사하는 시스템을 추가한다. 임의의 초당 HP/MP/허기 감소는 금지.
- 특수 기원 아이템이 활성화될 때 신뢰된 sourceId 경로에서 정의를 생성하고 금기·저장·UI·우회 제작 테스트를 동시 적용한다.

**현재 결론: I단계 일부 구현 및 자동 회귀 확장, 전체 완료 아님.**
