# 1단계 기술적 인수 기록 (2026-10-28)

범위: 현재 활성 제작법의 공통 제작 런타임과 UI/저장 자동 검증. 단일/일괄/중단 제작 동등성, 정확·범용 소재, 스택, 소비한 직전 재료 기록, 시간 상한, 생존 임계치, 작업대 접근, 이질 기원 장비 제작 금기, save v3, Linux/Windows/Chromium을 인수 기준으로 둔다.

코드 근거: tests/stage1-*.test.mjs, tests/05n-material-composition.test.mjs, tests/browser-stage1-workshop.mjs, tests/browser-03f-smoke.mjs. 해당 PR의 모든 CI가 성공하면 1단계 공통 기반의 기술 인수를 완료로 기록한다.

범위 밖: 실제 특수 수목 벌목과 식물 자원 연결은 II, 광물 콘텐츠 전반은 III, 수생 포획 및 이질 소재 실제 획득 경로는 IV, 전체 장기 수동 플레이와 밸런스 검수는 V단계에서 다룬다. 생존의 초당 자연 감소율은 미확정이며 기본값 0. 명시적 감소량에 대해서만 제작 사이 안전 중단한다. 배치 설비와 소유형 도구의 확장은 관련 시스템 정의 후 진행한다. 헤드리스 브라우저 검사는 수동 QA가 아니다.
