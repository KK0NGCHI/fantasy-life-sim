# UI v0.3 설계 기록

작성일: 2026-10-22. 본 문서는 인터페이스 설계·구현 범위를 다룹니다. 게임 규칙의 미확정 사항은 확정하지 않았습니다.

## 반영 사항
1. B형 2단 패널: 큰 메인 화면과 우측 플레이어/기록. 좌측 메뉴 제거, 하단 버튼·단축키 채택.
2. 상단에는 날짜·시간·골드. 플레이어 상태(HP·MP·EXP·허기·상태 이상)는 우측 상단에 배치.
3. 상태 이상은 9종 목업, 기본 6개 아이콘 노출. 전체 보기 지원. 마우스 오버와 키보드 포커스에 상세 효과·남은 턴 표시. 실제 상태 이상 계산은 미구현.
4. Lucide UI 아이콘 일괄 적용. 유니코드 특수문자 조작 아이콘 제거. 콘텐츠 아이콘 Game-icons.net은 나중에 개별 저작자 표시와 함께 도입.
5. 왼쪽 로고, 탭의 좌측 강조선, UI MOCKUP 머리말, 생활 화면의 중복 세계 지도 버튼 제거.
6. 사건 기록 검색 제거. 종류 필터·연속 메시지 묶기·고정·상세 펼치기 유지.
7. 지역별 컬러 스폿과 작업 상태색을 도입. 일반 UI는 흰색과 중립색을 사용하며 색상은 실제 콘텐츠 표현에 집중.
8. 인벤토리·캐릭터·숙련·도감·신앙은 넓은 native HTML dialog로 열림. 키보드 Escape 닫기, 기존 화면 유지.

## 참고 자료
- [Lucide 공식 문서](https://lucide.dev/) — SVG 선형 아이콘, 일관된 스타일과 크기/획 두께 설정. [라이선스](https://github.com/lucide-icons/lucide/blob/main/LICENSE)는 ISC 및 일부 Feather 유래 아이콘의 MIT.
- [RimWorld Wiki: User interface](https://rimworldwiki.com/wiki/User_interface) — 하단 메뉴, Inspect 패널, 리소스 목록 등의 영역별 역할에 대한 설명. 이 게임에서는 하단 전역 메뉴와 선택적 상세 창의 원리만 참고.
- [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) — Escape/Tab, 트리거로 포커스 복귀 등 참고. 현재 코드에서는 라이브러리를 쓰지 않고 native dialog를 이용.
- [Game-icons.net FAQ](https://game-icons.net/faq.html) — 다수의 아이콘에 CC BY 저작자 표시가 필요. 현재 적용 자산 없음.

## 남은 검증 과제
- 1366×768 및 1920×1080, 좁은 화면에서 플레이어 패널과 메뉴의 실측 검사
- 클릭/키보드 이동, 모달 재오픈 시 포커스 복귀 동작 확인
- 다수 상태 이상 툴팁 위치 및 잘림 문제
- 시각적 명도 대비와 글꼴 가독성 검사
- Lucide 아이콘을 로컬 번들로 전환하여 오프라인에서도 보이게 만들기
- 성장/경제/상태 이상/던전/제작의 실제 게임 로직 구축

GitHub Actions 검사는 코드의 구문 및 간단한 파일 계약 검증이며 브라우저 UI 통합 테스트를 대신하지 않습니다.
