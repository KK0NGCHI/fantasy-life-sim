# Somnium 자원 확장·활용 관계 설계 v0.4 (추가분)

> **상태: 검토 후보 / 구현 보류.** 작성 2026-10-27. 기존 v0.3의 지역별 256개 후보를 폐기하거나 덮어쓰지 않는다. 이번 자료는 16개 지역에 8개씩 **128개 지역별 원천 배치 후보**를 추가한다. 합산 범위는 **384개 지역 배치**이며 고유 종수는 중복 통합 전까지 미정이다. 본 문서와 관계표는 독립적으로 GitHub에서 읽을 수 있다.

## 기준과 용어
- 지역별 자원은 종·광상·유물·시설·관찰 대상을 포함한다. 동일종의 중복 지역 배치는 하나의 정식 sourceId로 통합한다.
- 표의 모든 산출물과 활용처는 제안이며 실제 구현이나 안전한 식용을 보증하지 않는다. 별표(*) 자원은 신규 판타지 세계관 후보로 이름과 설정이 미확정이다.
- 관계는 원천 → 획득물 → 가공/중간재 → 소비·연구·전시·교역으로 기록한다. CSV/TSV 원장에서는 임시 rowId를 사용하며 기존 런타임 ID와 혼동하지 않는다.
- 기존 코드 기준: src/resource-catalog-05a.js, src/resources-05a.js, src/fungal-ecology-05b.js, src/mineral-atlas-05e.js, src/mineral-refining-05h.js. 카탈로그에 있다고 실제 획득/제작 가능하지는 않다.

## 세계관 불변사항
- 16개 기본 지역과 별도의 깊은 숲·심층 광산·심해·심층 미궁. 심해는 단순 낚시 레벨로 접근하지 않는다.
- 인벤토리 음식은 부패하지 않음; 밭 과숙 작물 부패는 가능. 수목 비파괴 채취와 벌목 구분.
- 일반 축산 산물은 정확히 우유·고기·가죽·양털·알의 5종. 몬스터 특수 부산물 별도. 식성은 초식·육식·잡식(골렘 포함)·이질식 4종, 이질식 사료 레시피는 하나.
- 베르단의 신성 수목 벌목, 네레이아의 신성 수생 생물 포획·살해, 칼두르의 이질적 출처 소재를 이용한 장비 제작 금기는 행위·출처 조건을 기준으로 판정하고 사전 고지한다.
- 종별 정체성은 보존하면서 family/form/grade/traits/재료 역할별로 범용 대체 제작을 허용한다. 가공 시 속성은 보존·감쇠·변환·제거를 명시하며 모든 특성을 무조건 전승하지 않는다.

## 정규화 관계표
동일 폴더의 [resource-relations-v04.tsv](./resource-relations-v04.tsv)는 위 128개를 행 단위로 연결한다. 산출물이 다수인 셀은 승인 전 각각의 itemId로 분리한다. 기존 v0.3 원천과 중복되는 항목은 새 sourceId 생성 금지, 기존 ID 참조로 표시한다.

## 레퍼런스와 적용 범위
- [Core Keeper — Biomes](https://corekeeper.atma.gg/en/Biomes): 지역마다 다른 광물·생물·진행 동기를 배치하는 패턴.
- [Core Keeper — Fishing](https://corekeeper.atma.gg/en/Fishing): 낚시 보상에 물고기 외 잡화·광석 등을 섞는 패턴.
- [Sun Haven](https://sunhaven.wiki.gg/): 판타지 생활과 농업의 동시 구성.
- [Dwarf Fortress — Industry](https://dwarffortresswiki.org/index.php/Industry): 산업 간 중간재 연결.
- [Kew POWO](https://powo.science.kew.org/about): 현실 식물의 종명·분포·용도 검증 출발점.
- [Kew 분류 자원](https://www.kew.org/science/collections-and-resources/data-and-digital/names-and-taxonomy): 균류 학명 검증.
- [Mindat](https://www.mindat.org/): 광물 분류 검증.
- 고유 설정·고유 소재명의 복제 없이 시스템 원리만 참조. 각 현실 후보의 생육지/식용/보호상태는 종별로 추가 검증해야 한다.
