# 05-F 광상 단위 저장 이전 안전성 게이트

## 현재 적용
- 광상 구성별로 05-E 유한 광맥을 **읽기 전용 그룹**으로 모으는 미리보기 `previewDepositMigration05F`를 추가한다.
- 단일 광상 그룹에는 기존 광맥의 `siteId`·`itemId`·재고·최대 재고·발견 상태가 그대로 들어간다.
- 그룹의 `remaining`은 단순 합계다. 별도 소비 가능한 두 번째 재고가 아니므로 **이중 채굴이 발생하지 않는다**.
- 모든 사이트 수량·총합·구성 관계를 다시 검사하는 `validateDepositMigrationPreview05F`를 제공한다.
- 입력 자료가 잘못되었을 때 자동 초기화하지 않고 실패를 반환한다.

## 아직 하지 않는 것
- 기존 save-v3 데이터 변형, 자동 마이그레이션, 저장 시 새 데이터 추가
- 광상 1개에서 복수 광물이 동시에 나오게 하는 채굴 명령
- 품위·부산물·암석층·심도별 출현 규칙의 실동작
- 자동 광산 채굴·광상 그룹의 UI 조작

## 다음 병합 전 필수 조건

- 개별 광맥의 잔량/발견 상태/ID 순서에 무관한 결과 비교
- 신규 광상 수량에 대한 RNG·중복 보상·고갈 처리 회귀 검사
