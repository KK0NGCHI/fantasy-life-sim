# Stage I 통합 검수 현황 (2026-10-28)

## 이번 검수 범위
- 전체 활성 레시피의 작업대 ID, 시간, 결과물 기본 조건을 감사한다.
- 수동 1회×N과 전량 제작 N회의 실제 재료 구성·재고가 같음을 검증한다.
- 재료 정의 선택, 재고 스택 고정, 재료 고갈/시간 예산 중단의 상호작용을 회귀 검사한다.
- UI에서 장비 제작 금기 사전 안내를 표시한다. 출처는 항상 서버 정의로 판정되며 경고 문자열만으로 금기를 적용하지 않는다.
- 저장/불러오기 및 플랫폼 테스트는 기존 05-N, Stage I 통합 테스트와 CI를 재실행한다.

## 발견된 남은 설계/구현 공백
- 엔진의 현행 `V2ActionDispatcher`는 제작 핸들러를 한 번 실행한 후 턴과 시간을 일괄 적용하며, 그 사이 HP·MP·허기 변화는 없다. 따라서 **제작 중 생존 임계치 지속 검사**는 현재 아키텍처에서 불가능하며, 제작 시작 검사만 구현됐다.
- 생존 시간 경과 모델을 먼저 정의하고 각 제작 완료 단위에 적용하는 방식으로 설계해야 한다. 이 기능 없이 '자동 제작 생존 안전 완성'이라고 표시하지 않는다.
- 이질 원천과 장비 레시피의 정식 source ID 매핑 및 획득 경로, 신성 수목 벌목/신성 수생 포획의 획득 액션 금기는 각각 후속 자원 분야의 콘텐츠 활성화와 연계한다.
- 작업대·도구의 개별 제작 조건 확대, 실제 UI 수동 사용성 검수 역시 Stage I 완료 게이트에 남는다.

**결론:** 이번 PR은 Stage I 통합 테스트 강화이며 단계 완료 선언이 아니다.
