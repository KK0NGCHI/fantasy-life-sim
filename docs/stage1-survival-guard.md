# 1단계: 반복 제작 생존 임계치 — 현재 구현 범위

2026-10-28. `craft.until`의 **명령 시작 시점**에만 선택적으로 HP/MP/허기 하한을 확인한다. 값은 사용자가 지정할 수 있는 안전 임계치(0 이상 유한한 수)이며, 미설정 항목은 검사하지 않는다. 상태가 임계치 미만이면 0턴·0소비로 거절한다.

UI는 생존 검사 끄기와 예시 보수 설정(각 하한 20)을 제공한다. 사용자 명령의 임계값이 게임 내 현재 상태를 바꾸지는 않는다. 이 정책은 현재 제작 중 시간이 흐를 때 생존 수치가 변화하는 **시뮬레이션을 구현한 것이 아니므로**, 제작 중 매번 검사하거나 실시간 긴 작업 취소를 제공한다고 주장하지 않는다.

작업 중 안전 중단을 온전히 제공하려면 통합 엔진의 시간경과/생존 변화 규칙과 턴 과금을 단위 작업별로 적용하는 전용 실행/중단 상태 모델을 설계해야 한다. 1단계 완료 이전의 남은 결함으로 추적한다. 저장 포맷 변경은 없다.
