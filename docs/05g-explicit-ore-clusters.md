# 05-G · 명시적 복수 채굴 묶음 안정성 게이트

이번 PR은 같은 지역과 같은 지질 광상 유형만으로 무관한 두 광맥을 동시에 채굴할 수 있었던 문제를 막는다.

- 다광물 채굴은 이제 검토용 허용 목록 `EXTRACTION_CLUSTERS_05G`에 속한 **정확한 site ID(지역·원료·index 0)** 2~3개에서만 가능하다.
- 시범 묶음: 황동석·황철석·섬아연석 / 석고·암염 / 현무암·부석 / 점판암·대리암 / 화강암·자철석.
- 허용 목록은 **물리적 광상 좌표를 이미 확인했다는 뜻이 아니다.** 추후 명시적 물리 광상·지층·심도 구조를 구축할 때 교체할 보수적 임시 연결이다.
- 그 외의 광물 조합은 설령 동일 지질 유형이라도 `UNVERIFIED_ORE_CLUSTER`로 전체 거부한다.
- 기존 `mineral.extract` 단일 자원 채굴은 변경하지 않고, `save-v3` 구조와 기존 원장의 매장량도 수정하지 않는다.
- 유효하지 않은 다광물 요청은 상태/난수/게임 시간을 소비하지 않으며, 성공 시 각 광맥에서 정확히 1개씩만 소비한다.

테스트: 열수 조합 허용, 다른 4개 대표 광상 조합 허용, 동일한 열수 계열이지만 목록에 없는 조합 거부, 중복 및 조작된 ID 거부.
