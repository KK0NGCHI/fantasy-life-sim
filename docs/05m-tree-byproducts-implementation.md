- `resource05A.treeByproducts05M` 사이드카는 성공한 수확에만 추가. 기존 v3 저장에는 필드가 없어도 정상이며 엄격한 키/수치 검증으로 조작·불일치 데이터를 거절.
- 도토리/솔방울/송진/수피/가지 등 **원재료 아이템**을 실제 획득한다. 가공 레시피는 후속 05-M3에서 실 사용처를 검증하며 추가. 원재료 자체를 완제품이라 주장하지 않는다.
- 독립 회복은 경과 게임 일수 기준 단순 시뮬레이션. 계절별 열매 맺음 조건과 벌목 후 새 나무 성장 시 기존 부산물 잔량 초기화는 후속 테스트 및 설계 검토 대상으로 남음.
- 신성 표기 없는 일반 나무 대상. 신성 수목 벌목 금기는 별도로 유지.
