# 05-E 통합 채광 화면

## 문제
기존 05-A 자원 작업, 별도의 05-A 검증용 수정 후보, 05-E 유한 광맥 탐사·채굴이 같은 광산 화면에 중복 패널로 나타났습니다. 각각의 매장량이 연동되는 경우에도 화면이 분리되어 사용자가 어느 동작을 해야 하는지 구분하기 어려웠습니다.

## 변경 사항
- 광산의 **자원 활동 → 채광** 탭에 하나의 기본 `통합 채광` 영역을 구성합니다.
- 광맥을 발견하지 않았으면 `광맥 탐사 (10분)`을 표시합니다. 발견 후에는 품위·경도·잔량·현재 보유 곡괭이 최고 등급과 `광맥 채굴 (3분)`을 표시합니다.
- 채굴 결과가 성공하더라도 광물 산출물이 없을 수 있으며, 로그에 산출물 0과 감소한 매장량을 표시합니다.
- 아래 **기존 작업 지점 · 공유 매장량** 구역에는 `resource.work` 작업 진행·도구 선택·지점 가용량과 동일 광맥 잔량을 나란히 표시합니다. 광맥이 0이면 작업 버튼이 비활성화됩니다.
- **추가 광물 발견 지점** 구역에서 기존 05-A 검증용 수정 후보 탐사·발견·작업 기능을 유지합니다.
- 비채광 자원 활동은 기존 탭과 엔진 명령을 유지합니다. UI의 모든 채광·탐사는 `executeV2`의 실제 명령 처리와 상태 재조회만 사용합니다.

## 자동 브라우저 검증
`tests/browser-05e-mineral.mjs`은 광산으로 이동, 단일 통합 채광 섹션 표시 및 기존 작업 지점 표시, 철광맥 탐사 후 도구 제한, 돌 광맥 탐사 및 채굴 후 재고 16→15 표시를 검사합니다.

## 한계
- 05-A 검증용 수정 후보 지점은 여전히 별도 데이터 모델입니다. 05-E 유한 광맥과 실제 지층 좌표로 합치지는 않았습니다.
- 현재 기본 탭 선택은 지역 자원 활동 종류에 따릅니다. 도구 교체 UI의 인벤토리 반영 및 저장 구버전의 신규 광맥 생성 마이그레이션은 별도 작업입니다.
- 광맥 위치와 깊이, 광산 자동 채굴의 일시중단/중단 조건 및 상세 접근성 개선은 후속 작업입니다.
- 임시 품위·채굴률은 최종 밸런스가 아닙니다.
