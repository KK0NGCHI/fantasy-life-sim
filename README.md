# 판타지 생활 시뮬레이션 — UI 시제품 v0.3

브라우저 기반 싱글플레이 판타지 생활 시뮬레이션의 UI 설계 단계입니다. 실제 성장·전투·경제·제작 시스템은 아직 연결하지 않았습니다.

## Windows 실행

기존 폴더에서 PowerShell을 열고:

```powershell
git pull
py -m http.server 8000
```

`http://localhost:8000`을 열고, 이전 화면이 남으면 `Ctrl + Shift + R`로 새로고침합니다. 종료는 서버 PowerShell에서 `Ctrl + C`입니다. Lucide 아이콘은 CDN에서 로딩하므로 인터넷 연결이 필요합니다.

## 조작 가능한 UI

- B형 2단 레이아웃: 메인 영역 + 우측 플레이어/사건 기록, 하단 메뉴, 상단 날짜·시간·목업 골드
- 지역별 다색 스폿과 생활 행동, 16개 지역 지도
- 플레이어 HP·MP·EXP 자리, 허기, 9종 목업 상태 이상 아이콘의 호버/키보드 포커스 상세 및 남은 턴
- 하단 메뉴: 생활·세계 지도·제작·인벤토리·캐릭터·숙련·도감·신앙·설정
- 큰 정보창: 인벤토리·캐릭터·숙련·도감·신앙. 인벤토리 검색·정렬·다중 선택과 상세 표시
- 사건 기록: 종류 필터, 반복 기록 묶기, 중요 기록 고정, 상세 정보. 기본 로그에서 턴 번호 생략
- 고정 컬러 타일 던전 이동, 자동 이동 시연, HP/MP/허기 중단 임계값
- 브라우저 로컬 저장소를 이용한 목업 퀵세이브 및 퀵로드

## 단축키

`I` 인벤토리, `C` 캐릭터, `M` 지도, `WASD` 또는 방향키 던전 이동, `F5` 목업 저장, `F9` 불러오기, `Esc` 큰 창 닫기.

## 기술 및 라이선스

`index.html`은 `src/v3.js`, `src/v3.css`를 로드합니다. v0.1과 v0.2 소스는 보존했습니다. UI 아이콘은 [Lucide](https://lucide.dev/)를 사용하며 ISC 라이선스(일부 Feather 유래 아이콘은 MIT)가 적용됩니다. [Game-icons.net](https://game-icons.net/)은 향후 콘텐츠 그래픽 후보이며 현재 적용하지 않았습니다. 세부 사항: [v0.3 설계 기록](docs/ui-v3-design.md).

현재 모든 재화·경험치·상태 이상·품질 수치 및 일부 지역 현황은 디자인 검사용 목업입니다.
