# 판타지 생활 시뮬레이션 · UI 시제품 v0.2

현재는 브라우저에서 조작할 수 있는 **인터페이스 목업**입니다. 게임 엔진이나 경제·성장 공식은 아직 구현되지 않았습니다.

## Windows에서 실행

이미 저장소를 내려받으셨다면 PowerShell에서 프로젝트 폴더로 이동한 뒤:

```powershell
git pull
py -m http.server 8000
```

브라우저에서 http://localhost:8000 를 엽니다. 종료는 PowerShell의 `Ctrl+C`입니다. 브라우저가 이전 화면을 캐시하면 `Ctrl+Shift+R`을 누르세요.

## 현재 실제로 조작되는 UI

- 생활 화면의 지역별 행동과 사건 로그, 세계 지도 16개 지역 전환
- 상단 HUD의 HP/MP/허기, EXP 자리, 목업 골드·시간·상태 이상
- 인벤토리 20개 목업 아이템: 종류 탭, 이름·소재·태그 검색, 정렬, 다중 선택, 선택 상세
- 캐릭터·숙련·제작·도감·신앙의 하위 탭/정보 배치 (대부분 목업)
- 사건 기록의 종류별 필터, 검색, 반복 기록 묶기/표시, 상세 펼치기, 중요 고정
- 고정된 컬러 타일 던전, 방향키/WASD 이동, 자동 이동 시연, 임계값 설정, 탐험 중 인벤토리·캐릭터 접근
- 설정에서 글자 크기 조절, 브라우저 로컬 저장소에 목업 퀵세이브·퀵로드

## 아직 구현되지 않은 게임 기능

실제 성장·EXP 계산, HP/MP/허기 소모와 회복, 시계 진행·행동별 시간, 골드 거래, 드롭/채집, 제작, 장비 효과, 전투, 랜덤 던전, 신앙, 경제, 복수 저장 슬롯 등. 화면의 예시 수치와 품질은 밸런스 확정이 아닙니다.

## 기술 구성

빌드/설치 없는 ES Modules + CSS입니다. `index.html`은 `src/v2.js`와 `src/v2.css`를 로드합니다. 이전 v0.1 구현은 `src/app.js`와 `src/styles.css`에 보존했습니다.

레퍼런스 조사와 화면별 구성은 [UI v0.2 조사 기록](docs/ui-v2-research.md)을 참고하세요.
