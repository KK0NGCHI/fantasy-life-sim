## 현재 main을 실행하는 방법

Node.js **22 이상**, Python 3 및 네트워크 접근이 가능한 환경을 기준으로 합니다. `main`에서 새 작업을 할 때는 먼저 최신 커밋과 열린 PR을 확인합니다.

```bash
git fetch origin
git switch main
git pull --ff-only
npm install
npm run check
python3 -m http.server 8000
```

Windows PowerShell에서는 서버 명령 대신 `py -m http.server 8000`을 사용할 수 있습니다. 브라우저 주소는 `http://localhost:8000/` 입니다. **`npm run check`에는 TypeScript 엔진 빌드 및 Node 테스트가 포함되며 `src/main-v2-inventory.js`가 `dist/engine/` 모듈을 가져오므로 빌드 전에 브라우저 화면을 여는 절차를 권장하지 않습니다.** `npm ci`를 사용하지 않습니다(현재 package-lock 미추적). UI는 `index.html → src/v3.js` 입니다.

자동 검증과 실제 Windows Chrome/Edge 사람의 수동 검수는 별개의 판정입니다. 개발 브랜치와 Draft PR 작업을 원칙으로 하고, 사용자 승인 없이 `main`을 병합하지 않습니다. 저장 파일과 기존 슬롯은 명시적 승인 없이 덮어쓰거나 자동 이전하지 않습니다.

**지금의 통합 목표:** M0 기준선 통합 이후 M1 '씨앗 → 재배 → 수확 → 제작·요리 → 판매 → 재투자 → 저장/복원'을 실제 UI에서 완성합니다. 자원·제작 Stage I의 기술적 인수는 게임 전체 또는 M1 완료가 아닙니다.

# 판타지 생활 시뮬레이션 — UI 시제품 v0.3

브라우저 기반 싱글플레이 판타지 생활 시뮬레이션의 UI 설계 단계입니다. 실제 성장·전투·경제·제작 시스템은 아직 연결하지 않았습니다.

## Windows 실행

기존 폴더에서 PowerShell을 열고:

```powershell
git pull
py -m http.server 8000
```

`http://localhost:8000`을 열고, 이전 화면이 남으면 `Ctrl + Shift + R`로 새로고침합니다. 종료는 서버 PowerShell에서 `Ctrl + C`입니다. Lucide 아이콘은 CDN에서 로딩하므로 인터넷 연결이 필요합니다.

## 조작 가능한 UI

- B형 2단 레이아웃: 메인 영역 + 우측 플레이어/사건 기록, 하단 메뉴, 상단 날짜·시간·목업 골드
- 지역별 다색 스폿과 생활 행동, 16개 지역 지도
- 플레이어 HP·MP·EXP 자리, 허기, 9종 목업 상태 이상 아이콘의 호버/키보드 포커스 상세 및 남은 턴
- 하단 메뉴: 생활·세계 지도·제작·인벤토리·캐릭터·숙련·도감·신앙·설정
- 큰 정보창: 인벤토리·캐릭터·숙련·도감·신앙. 인벤토리 검색·정렬·다중 선택과 상세 표시
- 사건 기록: 종류 필터, 반복 기록 묶기, 중요 기록 고정, 상세 정보. 기본 로그에서 턴 번호 생략
- 고정 컬러 타일 던전 이동, 자동 이동 시연, HP/MP/허기 중단 임계값
- 브라우저 로컬 저장소를 이용한 목업 퀵세이브 및 퀵로드

## 단축키

`I` 인벤토리, `C` 캐릭터, `M` 지도, `WASD` 또는 방향키 던전 이동, `F5` 목업 저장, `F9` 불러오기, `Esc` 큰 창 닫기.

## 기술 및 라이선스

`index.html`은 `src/v3.js`, `src/v3.css`를 로드합니다. v0.1과 v0.2 소스는 보존했습니다. UI 아이콘은 [Lucide](https://lucide.dev/)를 사용하며 ISC 라이선스(일부 Feather 유래 아이콘은 MIT)가 적용됩니다. [Game-icons.net](https://game-icons.net/)은 향후 콘텐츠 그래픽 후보이며 현재 적용하지 않았습니다. 세부 사항: [v0.3 설계 기록](docs/ui-v3-design.md).

현재 모든 재화·경험치·상태 이상·품질 수치 및 일부 지역 현황은 디자인 검사용 목업입니다.

## v0.3.1 인터페이스 개선

- 설정: 하단 메뉴에서 제거하고 상단 우측의 Lucide 설정 아이콘으로 이동
- 제작: 목록 40% / 선택 상세 60%, 제작 기록 탭 제거, 실제 작동하는 목업 정렬·필터 제공
- 인벤토리: 기존 정렬 외에 종류 필터를 추가 (목업 아이템 대상)
- 세계 지도: 16개 정사각형 버튼을 4×4로 중앙 배치, 버튼 내부 아이콘과 이름 중앙 정렬, 지역별 절제된 고유 색 적용. 버튼 크기는 창의 높이에 대응해 제한
- 던전: 타일 기본 29px에서 넓은 화면 36px, 중간 폭 화면 30px로 확대
- 사건 기록: 데스크톱에서 로그 패널을 274px 높이로 제한하고 기록 영역 내부에 스크롤 적용. 중앙 콘텐츠도 독립적으로 스크롤해 하단 메뉴가 화면에서 밀리지 않도록 수정
- 생활 지역 표현: 연한 초록/주황/파랑의 3색 패널을 제거하고 중립적인 회색·석재톤으로 통일. 세계지도에서만 지역 성격에 맞는 낮은 채도 차이를 유지

이번 수정은 게임 규칙이나 저장 데이터 포맷을 변경하지 않습니다. GitHub Actions 자동 문법 검사는 통과했지만 실제 브라우저에서 1920×1080 및 작은 창의 레이아웃은 별도로 확인해야 합니다.

## v0.4 시각 개편 (2026-10-22)

- 메인 지역 장면: 밝은 고채도 그라데이션을 지역마다 별도 구성. 겹친 방사형 그라데이션과 기울어진 선형 그라데이션 이용. 화면 밖 UI는 화이트 기반 유지.
- 월드맵: 버튼 한 변 최대 122px(이전 최대 112px), 제목 기본 16px/보통 굵기, 테두리 없이 부드러운 사각형, 아이콘·제목 중앙 정렬. 화면 높이가 작은 경우 자동 축소.
- 생활 행동: 긴 가로 버튼 대신 아이콘이 위에 있는 작은 정방형에 가까운 버튼 사용.
- 인벤토리: 링크형 항목을 제거하고 선택 가능한 행 + 체크박스 + 별도 상세 정보로 구성, 기존 검색/정렬/필터 기능 유지.
- 던전: 지도를 메인 영역 가운데로 정렬하고 탐색 방향 조작을 우측 제어 패널로 이동(넓은 화면 기준). 화면 폭이 부족하면 제어판을 아래로 배치.
- 파일: `src/v4.css`가 `src/v3.css`를 가져와 새 색과 레이아웃을 적용, `src/v3.js`는 관련 UI를 수정.

**시제품 범위:** 모든 상태·경제·품질·성장 수치는 목업. 실제 기능 검증은 브라우저에서 필요. 고정 로그 높이와 퀵세이브 구성은 유지.

## v0.5 · 팔레트 선택 및 상태 이상 UI (2026-10-22)

- 상태 이상 설명은 스크롤 가능한 플레이어 패널 밖, 브라우저 화면 최상위에 고정 위치로 표시해 중앙 패널에 가려지지 않도록 개선했습니다. 호버 및 키보드 포커스를 지원하며 화면 경계 안에 배치합니다.
- 세계지도 지역 이름은 12px, 아이콘은 35px로 확대, 둘 사이 간격은 4px로 축소했습니다.
- 거점은 밝은 노랑·녹색으로 조정하고, 고대 유적과 지하미궁은 명도를 소폭 낮췄습니다.
- 기본 UI 색상을 보라/파랑/분홍으로 구성하고, 설정의 팔레트 미리보기에서 즉시 변경할 수 있습니다.
- 라이트: 오로라(자체 시안), Catppuccin Latte, Rosé Pine Dawn, Nord Aurora 기반.
- 다크: Rosé Pine Moon, Catppuccin Mocha, Dracula, Tokyo Night 기반.
- 팔레트 선택은 `localStorage`의 `fantasy-ui-theme`에 별도로 보존됩니다. 기존 목업 저장과 무관하게 유지됩니다.
- 유명 테마는 원본 색상의 **게임 UI용 재해석**이지 원본의 모든 토큰을 그대로 이식한 것은 아닙니다.

원본 자료: [Catppuccin](https://catppuccin.com/palette/), [Rosé Pine](https://rosepinetheme.com/ko/palette/), [Nord](https://www.nordtheme.com/docs/colors-and-palettes/), [Dracula](https://draculatheme.com/contribute), [Tokyo Night](https://github.com/tokyo-night/tokyo-night-vscode-theme).

CSS 테마 토큰은 `src/v5.css`에 있습니다. 기존 스타일은 `src/v4.css`에 보존됩니다.

## v0.6 팔레트 다양화 및 다크모드 개선 (2026-10-22)

- 테마 선택 목록을 8종으로 다시 구성. 이름은 전부 한국어로 표시.
- 유지: 오로라, 장미빛 새벽, 장미빛 달, 도쿄의 밤.
- 추가: 솔라라이즈드(밝은 파랑·청록·황토), 그루브박스(어두운 주황·연두·청록), 상록의 숲(어두운 녹색·황금·청록), 시트러스(밝은 라임·호박·청록).
- 제거: Catppuccin Latte/Mocha, Nord Aurora, Dracula.
- 다크 테마에서는 **하단 단축키 키캡**, 하단 탭 hover·선택 상태, 설정 입력창, 제작/인벤토리 목록, 로그와 세부 정보 패널의 배경/테두리/텍스트를 공통 테마 변수로 정리.
- 지역 그라데이션은 보존하되 어두운 테마에서 얇은 반투명 오버레이로 배경만 어둡게 처리. 텍스트와 아이콘은 함께 흐려지지 않도록 분리.
- 세계 지도 아이콘과 제목은 중앙 기준 아래로 3px 이동.
- 기존 이용자의 제거된 테마 설정은 유효하지 않으므로 오로라로 안전하게 대체.

## v0.7 인터페이스 마무리 (2026-10-22)

- **다크모드 제공 종료:** 테마 선택은 라이트 팔레트 8종으로 구성합니다. 오로라·장미빛 새벽·솔라라이즈드·시트러스 유지, 석류빛(빨강 중심)·푸른 항해(파랑 중심)·라벤더 들판·살구 코코아 추가.
- 기존 다크 테마 사용자 설정은 오로라로 자동 대체됩니다. 사용하던 이전 CSS 파일은 회귀 비교용으로 남아 있지만 현재 테마 선택에서 접근할 수 없습니다.
- **테마별 호버 색:** 하단 메뉴, 행동 버튼, 정보창 목록, 설정 버튼 등에서 각 팔레트의 hover 색을 사용하고, 마우스 오버 시 위로 움직이는 애니메이션을 제거했습니다.
- **던전 탐색:** 방향 조작 버튼을 실제 우측 제어 영역에 넣고, 지도와 제어 영역의 여백 및 너비를 개선했습니다. 기존 탐색 동작과 HP/MP/허기 자동 중단 조건은 그대로 유지합니다.
- **플레이어/로그 패널:** 양쪽 사이의 구분선을 드래그해 높이를 변경합니다. 키보드 방향키도 지원합니다. 조절값은 브라우저 저장소의 `fantasy-log-panel-height`에 저장합니다. 모바일에서는 구분선이 표시되지 않습니다.

공식 레퍼런스: [Adobe Spectrum interactive state colors](https://spectrum.adobe.com/page/using-color/) — hover/선택/키보드 포커스에는 의미별 색상 토큰을 사용합니다. 이 UI의 테마별 hover를 설계하는 원리로 참고했습니다.
