# 판타지 생활 시뮬레이션 — 인터페이스 시제품

한국어 싱글플레이 판타지 생활 시뮬레이션의 **Phase 1 목업 UI**입니다. 전체 게임 엔진이나 경제·성장 밸런스는 구현하지 않았습니다.

## 실행

1. 이 저장소를 다운로드 또는 `git clone` 합니다.
2. `index.html`을 브라우저에서 엽니다. 별도의 Node.js 설치나 서버가 필요하지 않습니다. ES Module 보안 정책상 일부 브라우저에서는 `file://` 실행이 제한될 수 있습니다. 그 경우 `python -m http.server 8000` 실행 후 `http://localhost:8000`을 엽니다.

## 이 시제품에서 조작할 수 있는 것

- 16개 지역 전환, 예시 생활 행동, 가상 턴·이벤트 로그
- 인벤토리 검색·종류 필터·수량 보기, 숙련 목록, 도감 및 제작 설명
- 지하미궁에서 컬러 타일 지도와 방향키/WASD 이동, 탐색 목업
- 던전 전용 자동 탐색 설정: HP·MP·허기 임계값 각각 활성화 가능
- 퀵세이브/퀵로드(브라우저 로컬 저장소에 **목업 상태만** 저장), 화면 글꼴 크기

## 비구현 및 주의

모든 콘텐츠와 스테이터스의 숫자는 **디자인 검사 전용 목업**입니다. 행동은 실제 채집 성공률, 시계 규칙, 성장 XP, 제작/전투/경제 계산을 수행하지 않습니다. 자동 탐색은 위험 판정이나 완전한 던전 생성 대신 경로 위의 샘플 타일 이동을 보여주는 데모입니다. 실제 퀵세이브 아키텍처(IndexedDB, 복수 슬롯, 버전 마이그레이션, 파일 import/export)는 Phase 2에서 구현합니다. 목업 저장을 실제 게임 저장 포맷으로 사용하지 마세요.

## 다음 기술 단계

첫 UI는 의존성 없는 JavaScript/CSS로 만들어 사용성과 색상, 레이아웃을 빠르게 비교합니다. 게임 코어를 구현할 때는 **TypeScript + React + Vite**, 데이터 정의를 JSON/스키마 검증으로 분리하고 상태 변경을 순수 게임 로직에 집중시키는 방식이 유력합니다. 도입 확정 전에는 실제 수직 슬라이스를 통해 구조를 검증합니다. 서버·멀티플레이는 만들지 않습니다.
